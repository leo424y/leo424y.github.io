# Cross-cultural_communication

跨文化溝通知識書庫（Markdown）。

- `data/`：文獻筆記，含摘要、思與行、來源連結。
- `note/`：原子化永久筆記，含交叉引用。
- `idea/`：由文獻與永久筆記延伸出的實踐構想。
- `term/`：概念定義、雙向概念連結與中英文維基百科連結。
- `moc/`：概念地圖與 Mermaid 關係圖。
- `Cross-cultural_communication.md`：中文導讀、全書論點、閱讀路徑與筆記索引。

所有檔案以 UTF-8 Markdown 儲存。部分維基百科中文連結在條目缺失時可能導向較泛用頁面；學術來源請以 DOI 或出版者頁面為準。
