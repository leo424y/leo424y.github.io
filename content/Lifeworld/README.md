# Lifeworld 書庫

本資料夾以 Markdown 建立生活世界（Lifeworld／Lebenswelt）主題知識庫。

- `data/`：文獻筆記，附來源與連結
- `note/`：永久筆記，以單一概念為單位並交叉引用
- `idea/`：靈感筆記，從研究延伸出思考與行動
- `term/`：概念定義、雙向 wikilinks 與中英文維基百科索引
- `moc/`：概念地圖與 Mermaid 關係圖
- `Lifeworld.md`：全書導讀與閱讀路徑

建議以 Obsidian 或 Logseq 開啟。檔名採中文結論式標題，未加編號。所有 Mermaid 圖以 fenced code block 保存，支援 Mermaid 的 Markdown 閱讀器可直接渲染。
