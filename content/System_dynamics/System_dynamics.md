# 系統動力學：理解回饋、累積與長期變遷

> System Dynamics｜卡片盒筆記書庫｜整理基準：2026-11-03

本書庫將系統動力學視為一種理解「系統結構如何產生時間行為」的方法。它不只是把事物畫成關係圖，而是追問回饋、存量、流量、延遲與非線性如何共同形成增長、震盪、停滯、超越或崩落。量化系統動力學通常再將這些關係寫成方程式，以連續時間模擬不同假設與政策情境。

本書庫從 1950 年代 MIT 的工業動態脈絡出發，連結 Donella Meadows 的系統思考與槓桿點、John Sterman 的模型方法與科學謙遜，再延伸到公共衛生、氣候能源、水資源、食物系統、循環經濟、廢棄物治理及參與式建模。案例涵蓋美國與歐洲的理論發展、南非水能源關聯、中國能源排放、印尼塑膠與社區廢棄物、墨西哥城市農園，以及台灣水資源、家庭用水、石門水庫與濁水溪流域研究。

## 本書的核心主張

系統動力學的價值，不在於宣稱能精準預知複雜未來，而在於把原本隱藏的結構與假設變得可見、可討論、可測試。模型是一種有用途、有邊界且必然不完整的表示；它應用來比較情境、學習政策後果和修正心智模型，而不是取代在地知識或宣告唯一解答。

尤其需要留意三個界線：第一，因果迴路圖是探索工具，不等於完整的量化存量流量模型；第二，情境模擬不是單一路徑預測；第三，參與式建模不會自動帶來公平，必須追問誰能定義問題、誰的知識被納入、誰承擔政策成本。

1. 文獻筆記以可取得的摘要、出版社頁面、期刊頁面或機構來源為依據；有些期刊全文可能需要機構訂閱。連結可作為查找入口，不代表本書庫已完整複製原文。
2. 研究案例的結果受模型邊界、參數、資料年份與制度環境限制。引用數值前，應回到原文核對方法、情境和修正紀錄。
3. 「系統動力學」和廣義「系統思考」並非完全同義。若研究只使用質性因果圖，應明確描述方法，不宜直接宣稱建立了量化系統動力學模型。
4. 這份書庫是可持續修訂的研究底稿，不是對所有國家和應用領域的完整系統性回顧。後續可逐步增加南亞、拉丁美洲、太平洋島國及更多台灣地方案例。
