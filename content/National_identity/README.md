# National_identity

此資料夾是以 Markdown 與 Obsidian wikilinks 建構的國族認同研究書庫。

- `National_identity.md`：全書導讀與索引
- `data/`：文獻筆記（含來源連結）
- `note/`：永久筆記（單一主張、交叉連結）
- `idea/`：靈感筆記（延伸問題與可行動方向）
- `term/`：概念定義（中英文維基百科連結）
- `moc/`：概念地圖（含 Mermaid 關係圖）

所有 wikilinks 以檔名作為標題；匯入 Obsidian 後即可使用。外部來源連結應在正式研究或引用前再次核對版本、頁碼與資料使用條款。
