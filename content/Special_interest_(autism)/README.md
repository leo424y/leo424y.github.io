# 書庫使用說明

- `data/`：來源與文獻卡片，含可追溯連結、研究摘要、限制與延伸思考。
- `note/`：由多份來源歸納的原子化永久筆記，檔名為結論式標題。
- `idea/`：從研究與永久筆記延伸出的行動或研究構想。
- `term/`：概念定義與概念間連結，附中文／英文維基百科條目連結（無獨立條目者以相關條目註明）。
- `moc/`：Mermaid 概念關係圖與閱讀入口。
- 根目錄的 `Special_interest_(autism).md` 是全書導讀與建議閱讀路徑。

所有 Markdown 連結採 Obsidian wikilink 寫法。資料截至 2026-11-20；引用的研究摘要以原始出版頁、PubMed、PMC、政府或專業機構頁面為依據。研究結果應連同樣本、方法與限制閱讀，不作個人診斷或個別治療建議。
