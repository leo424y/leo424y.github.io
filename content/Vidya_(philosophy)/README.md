# Vidya_(philosophy) 書庫

本書庫以 Markdown 與 Obsidian／Logseq 風格的 `wikilinks` 組織。所有檔名皆為中文結論式標題（根目錄導讀與來源索引除外），沒有編號。

- `data/`：來源導向的文獻筆記，含原典、研究論文、哲學百科、訪談與跨文化資料。
- `note/`：原子化永久筆記，整理可重組的概念與論證。
- `idea/`：從概念延伸出的反思、練習與行動方案。
- `term/`：術語定義、雙向概念關聯與中英文維基百科入口。
- `moc/`：概念地圖，含 Mermaid 關係圖與相關筆記連結。
- `Vidya_(philosophy).md`：全書導讀與閱讀路徑。
- `來源索引與延伸書目.md`：研究來源及建議深讀書目。

## 使用方式

將資料夾解壓後放進你的知識庫即可。若使用 Obsidian，建議啟用 Mermaid 支援並使用 wikilink 自動建立雙向連結。部分維基百科中文條目採用較廣義的相關主題入口，並非每個梵語術語都有獨立中文條目；遇到術語語義差異時，請優先回到原典與學術來源。

## 編輯提醒

此書庫是研究導讀與知識整理的起點，不是對所有印度宗教哲學立場的統一判決。特別注意：parā／aparā vidyā 的解讀、ātman 與 anātman 的爭論、證言作為 pramāṇa 的地位，均存在學派差異。個別訪談應歸屬於受訪者，不可視為整個宗教傳統的代表性結論。
