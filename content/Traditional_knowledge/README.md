# Traditional_knowledge 書庫

本資料夾由 Markdown 卡片組成，適合 Obsidian、Logseq 或一般 Markdown 編輯器。

- `Traditional_knowledge.md`：中文導讀與閱讀路徑
- `data/`：文獻來源與個案
- `note/`：永久筆記
- `idea/`：靈感與行動
- `term/`：概念定義與維基百科連結
- `moc/`：概念地圖（Mermaid）

每張卡片都連回導讀；導讀則索引所有卡片，供雙向連結與知識圖譜使用。來源以公開網頁、官方文件、學術研究與社群組織出版品為主。對於需要社群授權的知識，不因其公開可搜尋而推定可以任意再利用。
