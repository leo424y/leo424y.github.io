# Vijñāna 書庫

本資料夾依卡片盒筆記方式整理。所有筆記採繁體中文與結論式檔名，Markdown wikilinks 可在 Obsidian、Logseq 等支援雙向連結的知識系統中使用。

本版共含 35 篇文獻筆記、14 篇永久筆記、7 篇靈感筆記、64 篇概念定義與 5 張概念地圖。文獻範圍涵蓋印度佛教與其他印度哲學、巴利經典、漢傳唯識，以及朝鮮半島、日本、藏傳佛教與當代意識研究。

- `Vijñāna.md`：全書導讀與閱讀路徑。
- `data/`：文獻筆記，附原典、研究、訪談或詞典來源連結。
- `note/`：永久筆記，每張卡片聚焦一項可重組的觀點。
- `idea/`：靈感筆記，將概念延伸為問題、思考與行動。
- `term/`：概念定義與中英文維基百科入口。
- `moc/`：概念地圖與 Mermaid 關係圖。

## 編輯提醒

1. `Vijñāna` 是跨傳統詞彙；各筆記會標示佛教、印度哲學或當代研究語境，不應將不同用法視為同義。
2. 古典教義、學術詮釋、第一人稱經驗與當代實證研究分屬不同證據層次。
3. 部分維基百科連結可能因語言版本或條目命名而變動；若條目不存在，請以連結的英文條目或原始來源追查。
4. Mermaid 圖在支援 Mermaid 的 Markdown 閱讀器中呈現。
