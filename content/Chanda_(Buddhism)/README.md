# Chanda (Buddhism) — Markdown 專題書庫

本資料夾依卡片盒筆記法建立：

- `data/`：文獻筆記，記錄經典、論書、研究、講座與書籍來源。
- `note/`：永久筆記，每張卡片集中處理一個可重組的概念。
- `idea/`：靈感筆記，將概念轉為可測試的思考與行動。
- `term/`：概念定義，附原語與維基百科中／英文參考入口（若條目未建立或內容不足，以專門來源為準）。
- `moc/`：概念地圖，使用 Mermaid 呈現關係。
- `Chanda_(Buddhism).md`：根目錄導讀與建議閱讀路徑。

以 Obsidian 等支援 Wikilinks 的 Markdown 軟體開啟，可使用 `[[資料夾/檔名]]` 建立筆記連結。Mermaid 圖需使用支援 Mermaid 的閱讀器。

重要方法提醒：chanda 的語義依早期經典、上座部／說一切有部／瑜伽行派論書與當代教學而異；中文「欲」亦可能對應不同原語。不要把所有 chanda 等同善欲，也不要把佛教離欲理解成消滅所有行動動機。
