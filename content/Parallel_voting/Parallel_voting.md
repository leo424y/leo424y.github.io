# 並立式投票：混合選舉制度的設計、代表性與政治競爭

並立式投票（Parallel Voting / Parallel System）是一種混合選舉制度：選民透過選區選舉與比例代表選舉等不同層次產生同一議會的代表，但兩個席次層次各自計算，比例代表席次不會依選區席次進行補償。它看似把地方問責與政黨比例代表結合，卻不保證最終議席分配與總體得票比例一致。

本書將並立制當作制度設計與民主代表性的案例來讀，而不只整理一個投票技巧。核心問題包括：席次公式如何將選票轉為議席？不同席次代表誰？選民如何在選區票和政黨票之間表達偏好？政黨如何跨層次協調？制度效果又如何受到政體、政黨組織和社會條件影響？

**閱讀提醒：** 並立制不是「只要有兩張票就是並立制」。應先確認席次是否互相補償；同一國家也可能在不同議院、不同年份採用不同制度。

## 核心觀點

### 一、並立制的定義來自席次計算，而非票紙數量

選民可能領到兩張票，也可能在同一張票上作出候選人與政黨選擇。只要不同層次的席次各自分配，且比例席次不補償選區席次，才符合並立制核心定義。參見[[並立制與聯立制必須依席次補償關係區分]]與[[並立制的兩個選舉層次互不補償]]。

### 二、地方代表與政黨代表並存，但未必對稱

選區代表通常面對特定地域的選民；名單代表通常更依賴政黨提名與政黨品牌。兩者可能提供互補的代表管道，也可能出現資源、地位與問責方式的差異。參見[[兩種選制疊加會同時產生地方代表與政黨代表]]及[[地方選區代表與政黨名單代表面對不同問責對象]]。

### 三、比例席次不代表整體比例性獲得保證

並立制的比例代表層次可以讓小黨取得部分席次，但如果比例席次數量有限，或選區席次集中於大黨，總體票席關係仍可能相當不比例。參見[[比例席次不能自動修復選區席次造成的不比例]]。

### 四、制度效果是規則與政治脈絡互動的結果

日本改革並未立刻消除舊有派閥與個人支持網絡；台灣研究顯示黨紀、選區服務與代表行為會相互影響；泰國、立陶宛、塞內加爾與俄羅斯的案例則顯示選制規則可以在不同政治環境中被反覆調整。參見[[選制效果會受政體政黨與社會脈絡調節]]。

| 國家／地區 | 案例定位 | 核心觀察 |

| 日本 | 眾議院並立制 | 289 席小選區、176 席比例代表；改革改變競爭，但舊政治慣例未必消失 |

| 俄羅斯 | 並立制的歷史與制度變遷案例 | 必須附上選舉年度，不宜把不同時期視為同一規則 |
| 韓國 | 準聯動比例代表制比較案例 | 2024 年不宜視為純並立制；可用來研究補償規則與衛星政黨策略 |
| 墨西哥 | 補償式混合制度的拉丁美洲邊界案例 | 名單席次具有校正票席失衡功能，不應直接歸類為純並立制 |

這份書庫把「混合選制」與「並立制」分開，不把任何有選區席次和名單席次的制度自動歸類為並立制。每個國家案例均應附議院、年份和法律版本。

## 研究方法與使用提醒

* **分類優先**：先確認補償關係，再給制度貼標籤。
* **時間切片**：任何國別制度都要附上議院、選舉年度、修法日期與適用規則。
* **多重指標**：同時觀察政黨得票與席次差距、地方問責、描述性代表、政策回應、有效政黨數及政黨策略。
* **多元證據**：把官方法規、選舉委員會說明、學術論文、問卷、訪談與選舉結果交叉比對。訪談可呈現參與者如何理解制度，但不能單獨證明整體因果。
* **不做單一價值排序**：治理穩定、比例性、地方連結、少數代表與制度可理解性可能互相衝突，應公開權衡依據。
