# Mutual_aid 書庫

本資料夾是一套以 Obsidian／Logseq 風格 wikilink 編寫的 Markdown 卡片盒。

- `Mutual_aid.md`：全書導讀、閱讀路徑與總索引
- `data/`：文獻筆記與來源連結
- `note/`：永久筆記，每張卡片處理一個核心主張
- `idea/`：靈感筆記與可測試行動
- `term/`：概念定義與中英文維基百科入口
- `moc/`：概念地圖與 Mermaid 關係圖

建議使用支援 Mermaid 與雙中括號筆記連結的 Markdown 筆記軟體開啟。若使用一般 Markdown 檢視器，wikilink 可能不會自動轉成連結。
