# Electoral_alliance

卡片盒筆記書庫，使用 Markdown 與 Obsidian/Logseq 風格 wikilinks。

- `Electoral_alliance.md`：根目錄導讀
- `data/`：文獻、研究與制度案例筆記
- `note/`：永久筆記
- `idea/`：靈感與行動延伸
- `term/`：概念定義及中英文維基百科連結
- `moc/`：概念地圖與 Mermaid 關係圖

建議以 Obsidian 開啟整個資料夾。部分中文維基連結使用搜尋頁，是因為中文條目名稱或專門條目是否存在需要個別確認；英文連結則指向相關概念條目。文獻筆記提供 DOI、出版社、研究機構或官方頁面連結。
