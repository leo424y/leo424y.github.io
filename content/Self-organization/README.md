# Self-organization 知識書庫

本資料夾採用卡片盒筆記結構，全部內容為 UTF-8 Markdown。

- `Self-organization.md`：全書導讀、閱讀路徑、概念索引與完整筆記索引。
- `data/`：來源卡片，包含研究論文、書籍、訪談、政策報告與不同地區案例。
- `note/`：一張卡片一個概念的永久筆記，含延伸思考與來源脈絡。
- `idea/`：由概念延伸出的生活／社群實驗與行動提案。
- `term/`：概念詞條，含雙向連結與中英文維基百科連結。
- `moc/`：概念地圖，含 Mermaid 關係圖與筆記連結。

內部連結使用 Obsidian 相容的 `筆記檔名` 語法。Mermaid 圖可在支援 Mermaid 的 Markdown 閱讀器中呈現。
