# Healthcare_in_Taiwan

這是一個以台灣全民健保為核心、連結國際制度比較的研究型卡片盒書庫。

- `data/`：文獻、官方統計、政策報告、訪談與跨國比較的來源筆記。
- `note/`：可重組的永久筆記，每張卡片聚焦一個主張。
- `idea/`：由文獻與永久筆記延伸出的研究問題、政策設計與社區行動。
- `term/`：概念定義、中文維基百科搜尋／條目及英文維基百科條目。
- `moc/`：以 Mermaid 呈現制度關係的概念地圖。
- `Healthcare_in_Taiwan.md`：全書導讀與閱讀路徑。

資料時間基準：主要採用截至 2026-11-24 可取得的官方文件、學術文章及國際制度資料。每份來源筆記保留原始連結；資料年份、分母與統計口徑不同時，不直接拼接比較。
