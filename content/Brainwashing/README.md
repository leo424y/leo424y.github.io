# Brainwashing 知識庫

本資料夾為繁體中文 Markdown 卡片盒知識庫。根目錄 `Brainwashing.md` 是導讀；各筆記以 Obsidian 相容的雙向連結格式互相連結。

## 內容規模

- 文獻筆記：22 篇
- 永久筆記：13 篇
- 靈感筆記：8 篇
- 概念筆記：22 篇
- 概念地圖：4 篇

## 資料夾

- `data/`：文獻與案例研究，附可追溯來源連結及研究限制
- `note/`：單一概念的綜合見解，連結相關資料
- `idea/`：延伸問題、團體設計與可實踐行動
- `term/`：概念定義與中英文維基百科檢索入口
- `moc/`：Mermaid 概念關係圖

## 使用提醒

「Brainwashing／洗腦」是有爭議的歷史與政治概念。本庫區分強制說服、思想改造、灌輸、宣傳、強制同化、虛假供詞與一般社會影響；引用時請回到原始文獻並注意出版年份、研究方法與證據限制。概念筆記中的維基百科連結採檢索入口，方便依語言查找條目。
