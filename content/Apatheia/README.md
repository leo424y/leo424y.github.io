# Apatheia 知識庫

這是一份以卡片盒筆記法整理的 Markdown 研究書庫。根目錄的 `Apatheia.md` 是全書導讀；資料夾依功能分為：

- `data/`：文獻筆記，保留來源連結、研究脈絡與限制。
- `note/`：由資料推導的原子化永久筆記，聚焦可重組的單一主張。
- `idea/`：延伸問題、生活實驗與可行動的思考。
- `term/`：核心術語定義、雙向 wikilinks 與中英文維基百科參照。
- `moc/`：概念地圖，附 Mermaid 關係圖。

所有筆記採繁體中文，檔名即標題，正文不重複列標題。內部連結使用 Obsidian wikilink；Mermaid 圖可在支援 Mermaid 的 Markdown／Obsidian 環境中檢視。

本書刻意區分古典斯多葛派、基督宗教修道傳統、早期道家及佛教平等心，不將它們簡化為同一種「情緒管理」。現代心理研究只按其研究設計與樣本作有限推論。
