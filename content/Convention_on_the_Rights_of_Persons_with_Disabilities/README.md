# 使用說明

這是一套以 Obsidian／Logseq 風格 Wikilinks 編排的 CRPD Markdown 知識庫。請將整個資料夾放入知識庫，並以根目錄的 `Convention_on_the_Rights_of_Persons_with_Disabilities.md` 作為入口。檔名即卡片標題；`data`、`note`、`idea`、`term`、`moc` 分別存放文獻、永久、靈感、概念與概念地圖卡片。

## 連結與版本提醒

- 筆記內以 Obsidian Wikilinks 連結其他卡片；若使用其他 Markdown 工具，請確認其是否支援 Wikilinks。
- 文獻筆記附有原始來源連結。公約、一般性意見、政府報告與倡議組織資料的證據性質不同，使用時請區分。
- 概念卡的維基百科連結以中文、英文相關條目作延伸閱讀；當百科尚無專門條目時，連至已存在且最接近的背景條目。
- CRPD 一般性意見第 9、10、11 號在本次整理時仍為提前未編輯版本，正式引用前請重新核對官方最新版本。
- 台灣的施行法與國際審查機制不等同於聯合國締約國身分或聯合國 CRPD 委員會對締約國的正式定期審查。
