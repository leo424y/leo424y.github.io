# 書庫使用說明

- `data/`：文獻筆記，記錄研究內容、方法脈絡與原始來源連結。
- `note/`：永久筆記，每張卡片聚焦一個可重組的知識主張，並與相關卡片互連。
- `idea/`：靈感筆記，將研究主張延伸為問題、觀察或可實作行動。
- `term/`：概念定義卡，只保留定義與概念連結。
- `moc/`：概念地圖，串起主題分支並作為導航入口。
- 根目錄 `Bioenergetics.md`：全書導讀、閱讀路徑與所有卡片索引。

所有內容為繁體中文。文獻狀態與來源以 2026-11-02 為整理基準；來源頁面如有更新，以原始出版物為準。卡片使用 Obsidian 雙向連結格式；匯入 Obsidian 後可直接建立知識圖譜。
