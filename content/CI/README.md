# 接觸即興：身體、關係與共同生成

這是一份可匯入 Obsidian 的 Markdown 卡片盒知識庫。

## 資料夾
- `文獻筆記`：學術研究、專書、歷史檔案與社群經驗；附外部來源連結與研究限制。
- `永久筆記`：跨來源歸納的可持續主張，含雙向連結。
- `概念筆記`：一張卡片定義一個概念，便於跨主題重組。
- `靈感筆記`：從閱讀延伸出的可測試練習與社群行動。

## 使用方式
將整個資料夾解壓縮後，使用 Obsidian 的「開啟資料夾作為庫」即可。入口為書名檔案；`目錄.md` 連結所有筆記，`索引.md` 依概念列出相關筆記。

## 編輯原則
- 不使用 YAML 屬性；檔名即筆記標題。
- 以繁體中文撰寫，保留 Contact Improvisation 與必要英文術語。
- 文獻摘要僅根據可取得的出版資訊、摘要或開放全文；無法取得全文時不推測細節。
- 全球案例是具體作者／社群敘事，不代表整個國家或地區。
- 練習建議以低風險探索為原則，不取代正式教學、風險評估、同意流程或專業治療。
