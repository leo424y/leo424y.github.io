# Cultural_landscape

本資料夾是以繁體中文撰寫的文化地景研究書庫，採卡片盒筆記結構。

- `Cultural_landscape.md`：全書導讀、閱讀路徑與索引。
- `data/`：文獻與案例來源筆記，每篇附原始來源連結。
- `note/`：原子化永久筆記，整理可跨案例重組的概念。
- `idea/`：由文獻與永久筆記延伸出的研究問題與行動構想。
- `term/`：概念定義、雙向 wikilinks 與維基百科中英文相關條目。
- `moc/`：主題概念地圖，包含 Mermaid 關係圖與筆記索引。

建議以 Obsidian、Logseq 或其他支援 Markdown wikilinks 與 Mermaid 的工具開啟。資料來源以官方文件、法律、學術論文、學術書籍及社群組織公開資料為主；部分近期論文僅能取得摘要，已在對應筆記標示限制。
