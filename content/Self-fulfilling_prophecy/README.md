# Self-fulfilling_prophecy 書庫

入口文件：`Self-fulfilling_prophecy.md`。本資料夾採 Markdown 與 Obsidian wikilinks。

- `data/`：文獻筆記，含研究摘要、限制與來源連結。
- `note/`：永久筆記，以單一論點串接不同文獻與概念。
- `idea/`：靈感筆記，將理論延伸為可嘗試的思考與行動。
- `term/`：概念定義與中英文維基百科搜尋入口。
- `moc/`：概念地圖與 Mermaid 關係圖。

建議使用 Obsidian 開啟整個資料夾，以啟用 wikilinks 與 Mermaid 圖形預覽。
