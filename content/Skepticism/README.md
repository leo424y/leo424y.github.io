# Skepticism 知識庫

本資料夾為 Obsidian 相容的 Markdown 知識庫，以卡片盒筆記法組織。入口請開啟 [[Skepticism]]。

## 使用方式

1. 解壓縮 ZIP。
2. 在 Obsidian 選擇「開啟資料夾作為庫」，選取 `Skepticism` 資料夾。
3. 從根目錄 `Skepticism.md` 開始閱讀；`moc/` 用來探索概念關係。
4. `[[資料夾/檔名]]` 是 Obsidian wikilink；一般 Markdown 連結則用於外部來源。

建立日期：2026-11-07。外部來源已附可點擊連結；部分維基百科條目可能因各語言維基的命名或收錄差異而需再校正。
