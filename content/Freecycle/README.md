# Freecycle｜Obsidian 卡片盒筆記書

這是一套以 Traditional Chinese 撰寫的 Obsidian Markdown 知識庫，包含序、目錄、概念索引，以及文獻、永久、概念、靈感四類筆記。

## 匯入方式

1. 解壓縮 ZIP。
2. 將 `Freecycle_Obsidian_Knowledge_Base` 資料夾直接作為 Obsidian Vault 開啟，或將資料夾內容複製到既有 Vault。
3. 開啟 `序與導航/目錄.md` 作為入口。
4. 若 Obsidian 尚未建立連結索引，可等待其掃描完成；筆記使用原生 `雙向連結` 語法。

## 筆記原則

- 不使用 YAML 屬性或編號檔名。
- 檔名即結論式標題；筆記正文不重複另列標題。
- 以一張卡片處理一個主要概念。
- 每張卡片包含「延伸思考與行動」與「脈絡與依據」兩部分。
- 文獻筆記區分官方自述、研究結果、個人經驗與組織影響數據。
- 概念索引只列出透過原生概念雙向連結明確連結的筆記。

## 資料與限制

資料檢索日期為 2026-10-31。Freecycle 會員數與地方群組數是檢索當下的公開頁面快照，會變動；部分文獻為單一地區案例或組織自述，不能直接推論全球情況。Freecycle、Freegle、Buy Nothing、Really Really Free Market、非正式回收與修理網絡在規則及勞動結構上並不相同，筆記中已保留其差異。
