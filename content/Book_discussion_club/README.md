# Book_discussion_club

這是一份可匯入 Obsidian 或其他支援 Markdown／wikilinks 的知識庫。

- `data/`：文獻與案例筆記，保留來源連結和證據限制。
- `note/`：可跨文獻重組的永久筆記。
- `idea/`：由研究與案例延伸出的活動設計和行動構想。
- `term/`：單一概念定義，含中文／英文維基百科參考連結。
- `moc/`：概念地圖與 Mermaid 關係圖。
- `Book_discussion_club.md`：全書導讀與閱讀路徑。

建議先將整個資料夾解壓縮，再以 Obsidian 的「開啟資料夾作為倉庫」方式匯入。所有檔名均使用中文結論式標題，方便在知識庫內以 wikilinks 連結。
