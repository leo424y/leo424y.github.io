# Affect_theory 書庫

本書庫以 Markdown 與 Logseq／Obsidian 可辨識的 雙中括號頁面連結語法 組織。資料夾不編號：

- `data/`：來源摘要、研究論文、書籍、訪談與案例；含來源連結。
- `note/`：可獨立重用的永久筆記；每張卡片聚焦一個論點。
- `idea/`：由概念延伸出的觀察、研究與實作提案。
- `term/`：概念定義、相關概念與中英文維基百科連結（若未找到可靠中文對應頁，會明確標示）。
- `moc/`：概念地圖與 Mermaid 關係圖。

入口文件為 `Affect_theory.md`。請從入口的閱讀路徑進入，再沿頁面內的雙中括號連結閱讀。

來源狀態：書目／摘要／作者訪談等以原始出版者、期刊或研究機構頁面為優先；連結可用性與全文開放狀態可能隨時間變動。理論爭議以並列呈現為原則，不把單一作者的主張寫成學界共識。
