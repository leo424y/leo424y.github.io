# Change_blindness

Obsidian / Markdown knowledge book on change blindness.

- `Change_blindness.md`: Chinese book introduction and reading map.
- `data/`: literature notes with source links.
- `note/`: permanent notes with synthesis and cross-links.
- `idea/`: exploratory ideas and actions.
- `term/`: concept definitions.
- `moc/`: maps of content.

The collection is a curated starter library, not a systematic review. Research coverage and limitations are described in the root guide.
