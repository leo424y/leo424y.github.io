# Substance_abuse 知識書庫

本資料夾以卡片盒筆記法整理物質使用、物質使用疾患、減害、治療、復元、政策與使用者權利。檔名採中文結論式標題；概念詞條使用英文識別名，並附中文名稱與中英文維基百科參考入口。

## 資料夾

- `data/`：文獻、報告、官方統計與案例研究摘要。
- `note/`：可獨立重組的永久觀點。
- `idea/`：由研究與觀點延伸出的問題、服務設計與行動構想。
- `term/`：概念定義與維基百科中英文參考。
- `moc/`：概念地圖與 Mermaid 關係圖。

主題導讀為 `Substance_abuse.md`。

## 研究界線

資料更新至 2026 年 11 月可查資料。全球統計需注意資料年份與估計口徑：UNODC 的過去一年藥物使用估計不等於物質使用疾患；WHO 酒精負擔與藥物使用疾患資料可能採不同年度。每張文獻卡均在參考段落附來源連結與必要限制。政策案例不視為可直接複製的模板。

本書為知識整理，不是診斷、個別治療或用藥指示。臨床處置需由合格專業人員與當事人共同決定。
