# 自創生：生命、認知與社會系統的自我生成

本資料夾依卡片盒筆記法整理，所有內容皆為 Markdown，可直接匯入 Obsidian、Logseq 或其他支援 Wiki links 的筆記工具。

- `data/`：文獻、論文、書籍、訪談與研究機構資料筆記。
- `note/`：原子化永久筆記，每張卡片聚焦一個主張。
- `idea/`：延伸思考與可執行的行動構想。
- `term/`：概念定義，附中英文維基百科連結。
- `moc/`：概念地圖，包含 Mermaid 關係圖與筆記連結。
- `Autopoiesis.md`：全書導讀、閱讀路徑及各資料夾筆記索引。

主題連結採用 `檔名` 格式。請以 `Autopoiesis.md` 作為入口。
