# Co-regulation 知識書庫

本書庫以繁體中文撰寫，保留英文術語與原始研究連結。主題導讀位於根目錄 `Co-regulation.md`。

- `data/`：以研究、回顧、民族誌與書籍為基礎的文獻筆記。
- `note/`：由多份材料歸納出的永久筆記。
- `idea/`：可延伸成日常實踐、活動設計或研究問題的靈感筆記。
- `term/`：概念定義與中英文維基百科搜尋入口。
- `moc/`：以 Mermaid 繪製的概念地圖。

所有筆記檔名均採中文結論式標題；主題根檔依要求命名為 `Co-regulation.md`。內部連結使用 Obsidian 相容的 `wikilinks`。
