# Time-based_currency

本資料夾是「時間本位貨幣：以時間交換重建互助經濟」的 Markdown 知識庫。

- 以檔名作為筆記標題，採不編號、原子化卡片。
- `data/` 保存文獻導向筆記；`note/` 保存跨來源永久筆記；`idea/` 保存延伸構想；`term/` 保存概念定義；`moc/` 保存 Mermaid 概念地圖。
- 筆記間使用 `檔名` 連結，可匯入 Obsidian、Logseq 等支援 Wikilinks 的工具。
- Mermaid 圖可在支援 Mermaid 的 Markdown 檢視器中渲染。
- 來源連結已直接寫入文獻筆記；部分期刊全文可能需要機構訂閱。
