# 八正道：從智慧、倫理到心智解脫的整體修行之道

八正道（Noble Eightfold Path）是佛教四聖諦中「導向苦滅之道」的具體內容，也是初轉法輪所說的中道。它由正見、正思惟、正語、正業、正命、正精進、正念與正定八個因素構成。這八支不宜理解為八項彼此分離的道德規則，也不只是按順序完成的八個階段；更適合把它看成一套相互支持的修行系統，涵蓋理解、意向、溝通、行動、生計、心智培育與禪定。

本書以早期經典為核心，並收錄上座部教學、越南禪的入世實踐、台灣人間佛教研究、安貝卡佛教與現代正念學術討論。各種材料會標示其證據層次：經典文本、傳統詮釋、現代研究或個人延伸。不同傳統不必被強行合併成一套單一解釋。

## 全書主旨

八正道所提供的不是一個要被崇拜的標準答案，而是一種持續檢查生活條件、心念、意向與行為的道路。正見讓人理解苦及其條件；正思惟使理解成為出離、無瞋與不害的意向；正語、正業與正命將倫理落實於關係和生計；正精進、正念與正定則培育心的穩定、清醒與洞察。三學（慧、戒、定）是理解這些功能的常見地圖。

《轉法輪經》把八正道定位為避開感官享樂與自我折磨兩種極端的中道；SN 45.8 逐項定義八支；MN 117 以正見為前導，展示道支之間的引生關係；SN 45.2 則把善友視為整個修行生活的重要條件。這些經文讓八正道同時具有個人、關係與共同體的面向。

## 八支概覽

| 支分 | 巴利語 | 核心方向 | 常見三學分類 |
|---|---|---|---|
| 正見 | sammā-diṭṭhi | 理解苦、苦集、苦滅與道 | 慧 |
| 正思惟 | sammā-saṅkappa | 出離、無瞋、不害的意向 | 慧 |
| 正語 | sammā-vācā | 遠離妄語、兩舌、惡口、綺語 | 戒 |
| 正業 | sammā-kammanta | 不殺生、不偷盜、不邪淫 | 戒 |
| 正命 | sammā-ājīva | 以不傷害的方式維持生活 | 戒 |
| 正精進 | sammā-vāyāma | 防止、斷除不善；生起、維持善法 | 定 |
| 正念 | sammā-sati | 身、受、心、法的覺察 | 定 |
| 正定 | sammā-samādhi | 心的穩定與禪定培育 | 定 |

三學分類是理解功能的常見方法，不代表八支只能屬於一個分類。八支彼此滋養，應放回完整道路理解。

## 全球脈絡與詮釋視角

- **早期印度佛教文本**：以 SN 56.11、SN 45.8、MN 117、SN 45.2、DN 22 等經文為基礎，辨認八正道的中道定位、支分定義、正見的前導作用、正念範圍與善友條件。
- **斯里蘭卡與上座部教學**：Bhikkhu Bodhi 的導讀提供三學分類和系統化說明；Walpola Rahula 的《What the Buddha Taught》則是廣受閱讀的現代入門著作。
- **越南禪與法國 Plum Village**：一行禪師將八正道連結深度聆聽、慈悲、非暴力與五項正念訓練，呈現入世佛教的當代實踐。
- **台灣與華語世界**：人間佛教研究討論太虛、印順及佛光山、慈濟等實踐，提醒讀者從歷史與社會脈絡理解佛教現代轉型。
- **印度社會解放思想**：安貝卡以自由、平等、博愛重新詮釋佛法，將佛教與反種姓壓迫及集體組織連結。
- **性別與制度研究**：泰國、斯里蘭卡與藏人社群的女性受戒研究，顯示普遍修行理想與制度權力之間可能存在落差。
- **當代正念研究**：學者對正念是否應保持佛教倫理脈絡，或可在世俗心理學中獨立研究，存在不同立場。閱讀時應區分實證研究、哲學主張與傳統規範。

## 閱讀時的辨識原則

1. **經典與詮釋分層**：經文、註釋、現代老師的教學、學術假說與個人實踐不是同一種證據。
2. **譯名保持開放**：正思惟、正意向、正定、正等持等譯法可能帶有不同取向，必要時保留巴利語。
3. **不把修行簡化成績效**：八正道不是自我優化的八項 KPI，也不是透過打卡換取道德優越感。
4. **兼顧個人與結構**：個人行動很重要，但生計、性別、制度與社會權力也會形塑修行條件。
5. **以減少苦與不害檢視實踐**：不只問自己是否感到平靜，也觀察言行、工作與共同生活造成的影響。
