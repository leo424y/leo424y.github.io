# Post-structuralism 書庫

此資料夾是 Markdown 格式的後結構主義知識書庫，可直接匯入 Obsidian、Logseq 或其他支援 Markdown 與 wikilinks 的筆記工具。

- `Post-structuralism.md`：全書導讀與閱讀路徑
- `data/`：文獻筆記與來源連結
- `note/`：原子化永久筆記
- `idea/`：延伸思考與行動靈感
- `term/`：概念定義、雙向概念連結與中文與英文維基百科延伸條目
- `moc/`：概念地圖與 Mermaid 關係圖

建議先開啟 `Post-structuralism.md`，再依閱讀路徑進入各 MOC。
