# Hermeneutic_Phenomenology

詮釋現象學主題知識書庫，Markdown 格式，適用於 Obsidian、Logseq 或一般 Markdown 編輯器。

- `data/`：文獻、哲學原典導讀、方法論與全球案例。
- `note/`：可獨立引用的永久筆記。
- `idea/`：從概念延伸出的研究問題與實作構想。
- `term/`：概念定義及中英文維基百科入口。
- `moc/`：概念地圖與 Mermaid 關係圖。
- `Hermeneutic_Phenomenology.md`：全書導讀與閱讀路徑。

筆記使用 `[[wikilinks]]` 串接。部分中文維基百科項目未必有獨立條目，相關概念卡以維基百科站內搜尋頁作為入口。文獻類型與證據層級有在卡片內註明；正式引用前請再次核對出版資訊。
