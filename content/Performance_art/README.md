# Performance Art Knowledge Base

Obsidian-ready Markdown knowledge base. Open this folder directly in Obsidian.

- `data/`: literature notes and source links
- `note/`: permanent notes with synthesized arguments
- `idea/`: fleeting notes and possible actions
- `term/`: concise concept definitions with reciprocal links
- `moc/`: maps of content
- `Performance Art.md`: book introduction and reading paths

The source notes are research summaries, not substitutes for the linked publications. Some sources are abstracts, catalog records, interviews, or institutional descriptions; read the original sources before using them as definitive evidence.
