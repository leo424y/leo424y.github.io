# 書庫說明

本書庫以公開可查的原典出版社頁面、學術期刊 DOI、政府／國際組織報告及研究機構頁面作為主要來源。英文原始材料為主，涵蓋歐洲理論、北美風險研究、日本福島、印度 Bhopal、拉丁美洲採掘衝突、中國環境參與、台灣核能與污染案例，以及太平洋原住民與地方知識。

## 使用提醒

- Beck 的風險社會論是宏觀理論框架，不應視為所有地區都已被同一模式涵蓋的經驗定律。
- 個案研究的研究設計不同：有理論論文、量化資料、訪談、民族誌、口述史及政策報告；筆記已盡可能標示方法，閱讀原文時仍應留意研究限制。
