# Information_ethics

本資料夾是「資訊倫理：在互賴的資訊世界中維護尊嚴、正義與共同福祉」的 Markdown 知識書庫。

## 資料夾
- `data/`：文獻與政策來源筆記，保留來源連結、摘要、限制與思考。
- `note/`：原子化永久筆記，以結論式標題表達可重組的觀點。
- `idea/`：從概念與文獻衍生的實踐提案。
- `term/`：術語定義與中英文維基百科入口。
- `moc/`：主題概念地圖，使用 Mermaid 關係圖。
- `Information_ethics.md`：全書導讀與閱讀路徑。

## 使用
將整個資料夾複製到 Obsidian vault 即可使用雙向連結。Mermaid 圖可在支援 Mermaid 的 Markdown 閱讀器中渲染。中文維基連結若尚無獨立條目，會導向維基百科站內搜尋。

## 編輯原則
一張永久筆記盡量表達一個可獨立理解的命題。文獻筆記摘要不是原文替代品；請點開原始來源閱讀全文，並留意法規與政策的最新版本。此知識庫為研究與教育用途，非法律意見。
