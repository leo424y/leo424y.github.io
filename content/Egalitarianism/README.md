# Egalitarianism 知識書庫

本資料夾以卡片盒筆記法整理平等主義，所有內容均為 Markdown，可直接匯入 Obsidian、Logseq 或其他支援 Wikilinks 的知識管理工具。

- `Egalitarianism.md`：全書導讀、閱讀路徑與索引。
- `data/`：文獻筆記，附學術、制度與研究來源連結。
- `note/`：永久筆記，每張卡片聚焦一項可重組的論點。
- `idea/`：靈感筆記，將理論延伸為可嘗試的行動。
- `term/`：概念定義與中英文維基百科連結。
- `moc/`：概念地圖，含 Mermaid 關係圖。

**建議使用方式：** 先讀 `Egalitarianism.md`，再按閱讀路徑進入 MOC、term、note 與 idea；文獻卡可用來追溯論點。Wikilinks 以卡片檔名為連結目標。

**研究限制：** 本書是具選擇性的跨區域入門知識庫，不是對所有平等思想傳統的窮盡整理。部分統計資料有不同年份與定義，請回到原始來源核對。
