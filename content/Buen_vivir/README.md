# Buen_vivir 知識書庫

這是一套可直接匯入 Obsidian 的 Markdown 卡片盒。

- `Buen_vivir.md`：全書導讀與閱讀路徑
- `data/`：文獻與原始資料卡
- `note/`：永久筆記
- `idea/`：延伸思考與行動提案
- `term/`：概念定義卡
- `moc/`：概念地圖（Mermaid）

所有內部連結使用 Obsidian wikilinks。外部來源連結已放在各文獻卡的「參考」段落。部分中文維基百科概念頁尚未建立，因此概念卡提供中文維基搜尋連結；英文維基連結則依實際條目或搜尋頁呈現。

建議使用 Obsidian 開啟資料夾根目錄，並啟用 Mermaid 圖表顯示。
