# 開源：自由、協作與數位公地

本書把 **Open source** 視為一種技術制度，也視為一種共同生產與治理方式。它從軟體原始碼的共享出發，逐步涉及使用者自由、授權制度、社群勞動、商業模式、資安、公共部門、開放科學、開源硬體與人工智慧。全書採卡片盒結構：`data` 保存來源與研究摘要，`note` 將材料轉化為可重組的論點，`idea` 將概念推進到可試驗的行動，`term` 提供詞彙定義，`moc` 則呈現主題之間的關係。

## 全書主張

開源不是單純「程式碼可見」，而是透過授權、文件、治理與實際能力，讓人們得以使用、理解、修改、分享並共同維護技術。它可以創造創新、互通與公共價值，但不會自動帶來自由、公平、安全或永續。這些成果需要明確的權利安排、包容的參與流程、維護資源、責任分工與公共制度。

## 跨領域閱讀的五個問題

1. **權利**：使用者能否合法使用、研究、修改、散布與退出？
2. **治理**：誰決定路線、合併程式碼、資金使用與領導接班？
3. **勞動**：誰承擔文件、支援、審查、安全與社群照護？
4. **公平**：誰有足夠時間、語言、設備、教育和網路參與？
5. **公共性**：開放成果是否能被本地社群理解、部署、維護並共同受益？

## 研究範圍與使用提醒

本書以可公開取得的組織文件、學術研究、政策報告、開放書籍與經典文章為主，兼顧北美、歐洲、印度、巴西及全球南方的案例。來源的性質並不相同：定義文件表達規範立場，研究論文提供特定方法下的證據，政策報告反映制度實務，倡議文章則呈現運動自身的價值論述。閱讀時應區分這些證據類型，不把倡議主張當成實證結論，也不把單一地區案例直接套用到其他地方。

授權與政策可能更新；實際採用軟體前，應重新確認授權全文、相依元件、專利條款、商標與當地法律。本文為知識整理，不構成法律或資安專業意見。概念詞條附有維基百科中文、英文及外文參照連結，應以各條目所列來源與一手文件為準。
