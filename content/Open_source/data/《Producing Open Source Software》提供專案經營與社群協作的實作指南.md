Karl Fogel 的《Producing Open Source Software: How to Run a Successful Free Software Project》第二版以免費線上形式公開，涵蓋開放專案的溝通、協作、版本發布、貢獻者管理與治理。它把成功專案視為需要有意識設計的社會過程，而非只要把程式碼上傳就會自然形成社群。適合作為建立專案流程與維護政策的操作手冊。

## 思與行
* 將這份材料與[[開源社群需要明確的治理與決策機制]]的論點對讀，分辨它提供的是定義、經驗證據還是政策主張。
* 檢查研究方法與適用範圍，避免把單一案例推廣為所有開源專案的普遍規律。
