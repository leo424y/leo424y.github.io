Open Source Definition（OSD）不是「程式碼在網路上看得到」的同義詞。它要求授權不得歧視個人或團體、不得限制特定領域用途，並保障再散布、取得原始碼、允許衍生作品及技術中立等條件。判斷某個專案是否開源，應檢查其授權條文是否符合定義，而不是只看 Git 儲存庫是否公開。

## 思與行
* 將這份材料與[[開放不等於公開原始碼而是可行使的權利]]的論點對讀，分辨它提供的是定義、經驗證據還是政策主張。
* 檢查研究方法與適用範圍，避免把單一案例推廣為所有開源專案的普遍規律。
