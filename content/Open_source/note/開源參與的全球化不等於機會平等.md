Git 平台讓協作跨越地理邊界，但可投入時間、語言能力、穩定網路、設備、教育、工作保障和人際連結仍不均等。地理分布研究與性別參與研究指出，參與機會會受到所在地與社會位置影響。印度跨產業研究也提醒，組織即使認同開源效益，仍可能缺乏專業人力與社群支援。[[開源貢獻者的地理分布仍呈現空間聚集]]與[[開源社群的性別多樣性與參與障礙因地區而異]]支持一個重要結論：開放的授權只是參與的起點，不是平等的保證。
