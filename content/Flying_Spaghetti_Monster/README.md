# Flying_Spaghetti_Monster 書庫

這是一份以繁體中文撰寫的 Markdown 知識書庫，採用卡片盒筆記結構，並以 wikilinks 和 Mermaid 概念圖連結各檔案。

## 資料夾

- `data/`：文獻、研究、法律文件、訪談、媒體與書籍的來源筆記。
- `note/`：可獨立重組的永久筆記，包含一個主要見解與延伸連結。
- `idea/`：由資料與永久筆記延伸出的研究、討論與實作構想。
- `term/`：概念定義與中文／英文／外文維基百科入口。
- `moc/`：概念地圖與 Mermaid 關係圖。
- 根目錄 `Flying_Spaghetti_Monster.md`：全書導讀、閱讀路徑、研究範圍與完整索引。

## 使用方式

建議以 Obsidian、Logseq 或支援 Wiki 風格內部連結的 Markdown 編輯器開啟。Mermaid 圖需在支援 Mermaid 的閱讀器中顯示。檔名即筆記標題，不另在卡片內重複標題。

## 編輯與引用原則

1. 法院判決、行政公告與官方組織自述屬於不同證據類型，請勿混為一談。
2. 區分團體登記、法人資格、婚姻證婚與個人宗教豁免等不同法律效果。
3. 對社群信徒人數、信仰真誠與各地法律現況，不以單一新聞或自述推論全體。
4. 來源連結供後續核對；法律與行政資料引用前宜回到原始文件確認最新狀態。

## 研究範圍

本版整理美國起源與個案、荷蘭與歐洲人權法院、奧地利、波蘭、紐西蘭、台灣及歐洲訪談研究，並納入宗教哲學、法律哲學、認知宗教科學與紀錄片等不同材料。這是有來源的研究型導讀，不宣稱已窮盡全球所有分支或全部相關文獻。
