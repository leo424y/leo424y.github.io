# 台灣前進陣線：歷史記憶、小黨合作與民主問責

「Taiwan Go Go」不只是一句鼓舞口號，也是一個跨越不同歷史情境的政治符號。本書以「台灣前進陣線」為當代核心個案，從1971年威廉斯波特少棒賽場上空的「GO GO TAIWAN」飛機布條談起，追溯海外台灣人社群如何透過跨國組織與公共行動表達政治訴求，再轉向2025年成立、協調2026年地方選舉的四黨合作陣線。

本書的主問題是：**理念不盡相同、資源有限的小型政黨，如何透過選舉合作轉化成可持續的民主力量？合作又如何維持內部自主、程序正當與外部問責？** 這不是單純判斷聯盟「成功或失敗」的問題，而是檢視組織設計、選舉制度、地方治理與公民監督能否形成一個可以不斷修正的政治實踐。

## 全書主線

### 一、歷史符號與跨國社群

1971年世界少棒賽期間，海外台灣人行動者租用小飛機，在賓州威廉斯波特球場上空展示「台灣獨立萬歲」與「GO GO TAIWAN」布條。口述史把這個行動放在海外台灣人社群的政治動員、冷戰環境與台灣國際處境中理解。1970年代，多個海外團體與島內行動者進一步透過世界台灣獨立聯盟（WUFI）等組織建立跨地域合作網絡。

當代台灣前進陣線借用「Taiwan Go Go」作為名稱與象徵，但歷史口號、早期海外運動組織與今日四黨陣線並非同一個組織，也不應被敘述成單線的組織延續。閱讀時可先看 [[data/威廉斯波特少棒賽場上的Go Go Taiwan飛機布條口述史]]、[[data/海外台灣人以跨國組織串連獨立運動的歷史資料]]，再讀 [[note/Go Go Taiwan的歷史記憶把海外抗爭與當代小黨合作連在一起]]，並搭配 [[moc/歷史記憶與跨國運動概念地圖]]。

### 二、當代陣線的形成與制度

台灣前進陣線由時代力量、小民參政歐巴桑聯盟、台灣綠黨與台灣基進共同組成，並與無黨籍夥伴合作。它的形成回應小黨在資源、媒體曝光、候選人培育與選區競爭上的困境；其合作方式包含共同綱領、選區提名協調、合作協調會議與候選人承諾。各成員黨有相交的進步、本土與公民參與價值，但仍保有各自的政治傳統與自主空間。

### 三、選舉制度與國際比較

選舉聯盟的效果並非只取決於政黨有沒有共同理念，也受到選制、政黨規模、支持度變化、提名規則、資源分配與選民如何辨識責任影響。芬蘭的共同名單研究，印度的聯盟破裂研究，紐西蘭的混合比例代表制經驗，以及德國小黨在聯合政府中的樞紐角色，提供不同的分析切面。這些制度不能直接套用到台灣；比較的重點是釐清制度差異，而不是複製別國模式。

### 四、從選舉競爭走向公共問責

聯盟取得席次不是終點。真正的民主能力，還要在地方議會質詢、預算審議、政策監督、資料公開與社區參與中接受檢驗。候選人資料圖鑑可以降低資訊取得門檻，但必須清楚標示資料來源、更新日期、法律狀態與更正方法，尤其不可把「遭起訴」直接等同「有罪」。共同政綱也應轉化成可追蹤的承諾、責任者、資料指標與回報週期。

## 研究界線與更新提醒

本書將資料分為官方自述、新聞報導、口述史、選舉機關資料與學術研究。官方網站可說明聯盟如何定位自身，但不能單獨證明其政策效果；口述史呈現參與者記憶，仍需其他史料交叉核對；學術研究提供比較理論，卻不能忽略不同國家的制度差異。筆記中的新聞與政策資料皆應回到原始來源確認日期與更新狀態。

本書整理時間以2026年11月10日為界。2026年地方公職人員選舉預定於**2026年11月28日**投票，因此本書不會預寫選舉結果或將未來事件當作既成事實。選後應補入實際當選名單、得票、政黨席次、議會組織、政黨協商及候選人承諾履行情況，並檢查聯盟在選後是否持續運作。

## 研究問題

1. 四黨如何在共同價值與政黨自主之間劃定合作邊界？
2. 選區協調能否減少彼此競爭，並實際提高小黨代表性？
3. 聯盟的決策規則是否能公平處理支持度與資源分配的變化？
4. 選民能否辨識聯盟共同責任、成員黨責任與個別候選人責任？
5. 取得地方議會席次後，聯盟能否轉化為透明、可檢核、持續參與的地方治理？
