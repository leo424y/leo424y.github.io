# Allostasis 知識書庫

這是一份以 Markdown 與 Wikilinks 組成的卡片盒知識書庫，可直接匯入 Obsidian、Logseq 或其他支援 Markdown 的工具。

- `Allostasis.md`：根目錄導讀與閱讀路徑
- `data/`：文獻筆記（含來源連結）
- `note/`：永久筆記
- `idea/`：靈感與行動筆記
- `term/`：概念定義與中英文維基百科入口
- `moc/`：Mermaid 概念地圖

建議先從 `Allostasis.md` 開始。此書庫的研究摘要截至 2026-11-11；預印本與新近研究會標示證據狀態。內容僅供知識整理，不構成醫療診斷或治療建議。
