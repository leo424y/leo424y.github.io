# Arousal 知識書庫

本資料夾是一套繁體中文 Markdown 卡片盒筆記，包含：

- `data/`：文獻、研究、專書與研究者訪談摘要，附來源連結。
- `note/`：永久筆記，以單一概念為核心並使用 Obsidian wikilinks 互相連結。
- `idea/`：延伸思考與可實踐的小型行動。
- `term/`：概念定義、相關概念與維基百科中英文條目。
- `moc/`：主題概念地圖與 Mermaid 關係圖。
- `Arousal.md`：全書導讀、閱讀路徑與全庫索引。

建議以 Obsidian 或支援雙中括號內部連結的 Markdown 編輯器開啟。Mermaid 圖需要支援 Mermaid 的檢視器。
