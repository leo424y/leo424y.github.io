# 公共圖書館：知識平權、公共生活與社區韌性的基礎設施

公共圖書館不只是借書的場所，而是由公共資源、知識近用、自由探索、地方關係與公共空間共同構成的社會制度。本書以全球公共圖書館的宣言、歷史、跨國比較、個案訪談與研究回顧為材料，探問一個核心問題：**公共圖書館如何讓不同背景的人，在不必消費或證明身分的前提下，取得知識、建立能力、與他人相遇並參與共同生活？**

全書採取多中心視角：國際層次以 IFLA–UNESCO 公共圖書館宣言作為規範基準；歐洲研究討論民主公共領域、移民與社會信任；哥倫比亞麥德林案例呈現圖書館與城市空間政策的結合；印度喀拉拉邦與肯亞案例凸顯社區網絡與共同治理；南非案例提醒數位服務受到歷史不平等制約；台灣研究則將圖書館置於地方韌性與災後復原的脈絡中；日本大久保圖書館案例呈現多文化街區如何透過合作網絡轉化圖書館角色。

本書不把公共圖書館浪漫化為能獨自解決貧窮、孤獨、數位落差或民主危機的萬靈丹。現有研究支持圖書館可以提供低門檻空間、資訊資源、學習支持與關係網絡，但實際效果受經費、制度、館員勞動、地方信任、空間管理與研究方法限制。尤其 2026 年的文獻回顧提醒，公共圖書館作為社會基礎設施的研究仍需更清楚說明作用機制，並擴大對偏鄉、非使用者及全球南方的研究。

## 全書主張

1. **公共性不等於形式上開門。** 真正的平等近用必須處理交通、時間、語言、障礙、費用、數位技能與心理安全等具體條件。
2. **圖書館的價值不只在館藏。** 空間、關係、資訊協助、終身學習、地方知識與跨組織合作同樣構成公共價值。
3. **民主功能發生在日常。** 自由取得資訊、查證公共議題、保護閱讀隱私與容納多元意見，都是民主公共領域的基礎。
4. **社區效益需要機制與時間。** 社會資本、信任與韌性不是活動人次的自然副產品，而是依賴持續互動、公共資源與公平治理。
5. **數位轉型必須以權利為中心。** 設備、技能、內容與隱私需一起設計，不能以監控換取便利，也不能把技術服務的責任推給使用者。
6. **圖書館必須接受公共檢視。** 成效評估應同時呈現服務規模、關係能力、社會成果與尚未被服務的人。

本知識庫以可公開取得的宣言、政策文件、書籍出版資訊、學術摘要、研究典藏與官方統計為起點。部分期刊文章可能只有摘要或需要機構訂閱；本文不把摘要視為完整論文，也不把個案研究的發現直接外推到其他國家。跨國比較時應注意公共圖書館制度、政府責任、地方自治、資源分布與文化脈絡的差異。統計資料需標註年份與口徑；研究回顧則需注意語言範圍、資料庫與納入標準。
