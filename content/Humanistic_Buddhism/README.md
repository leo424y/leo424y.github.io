# Humanistic_Buddhism

此資料夾為「人間佛教」卡片盒知識書庫，使用 UTF-8 Markdown 與 Obsidian 相容的雙括號內部連結。

- `data/`：研究論文、專書、官方資料與原典譯介，附來源連結。
- `note/`：一張卡片一個結論式命題，含思與行、參考與交叉連結。
- `idea/`：由永久筆記衍生的實踐構想與行動實驗。
- `term/`：概念定義、雙向概念連結及中英文維基百科相關入口。
- `moc/`：概念地圖、簡述與 Mermaid 關係圖。
- `Humanistic_Buddhism.md`：全書導讀、閱讀路徑與完整索引。

部分概念在不同學者及組織間有不同定義；請將永久筆記視為可持續修訂的研究命題，而非統一教義。官方資料用於理解機構自我定位，需與外部學術研究交叉閱讀。
