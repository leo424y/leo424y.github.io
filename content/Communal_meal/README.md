# Communal_meal

這是一個可直接匯入 Obsidian 等支援 Markdown wikilinks 的知識書資料夾。

- `Communal_meal.md`：全書導讀與閱讀路徑
- `data/`：文獻與案例研究筆記（附 DOI／來源連結）
- `note/`：原子化永久筆記
- `idea/`：可實驗的延伸思考與行動
- `term/`：概念定義與中英文維基百科相關條目
- `moc/`：概念地圖與 Mermaid 關係圖

請將整個 `Communal_meal` 資料夾放入筆記庫。部分概念的中文維基百科可能沒有完全對應的獨立條目，筆記中已在可用時連至相近條目；研究結論也保留各來源的研究設計與因果限制。
