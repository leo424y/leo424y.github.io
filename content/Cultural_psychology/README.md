# Cultural_psychology 書庫

這是一份以 Markdown 建立的文化心理學卡片盒書庫。

- `Cultural_psychology.md`：全書導讀、閱讀路徑與索引。
- `data/`：文獻筆記，附 DOI、出版社或機構來源連結。
- `note/`：永久筆記，以單一論點為單位，交叉引用概念與文獻。
- `idea/`：靈感筆記，保存可發展的研究問題與行動。
- `term/`：概念定義，含中英文維基百科入口及雙向概念連結。
- `moc/`：概念地圖，含 Mermaid 關係圖。

建議使用 Obsidian、Logseq 或其他支援雙中括號內部連結的 Markdown 工具開啟。Mermaid 圖需在支援 Mermaid 的閱讀器中顯示。

整理基準日期：2026-11-13。學術來源與網頁可能更新，正式引用前請再次核對出版版本、頁碼與 DOI。
