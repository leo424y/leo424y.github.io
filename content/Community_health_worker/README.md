# Community_health_worker

本資料夾為「Community Health Worker／社區健康工作者」主題的卡片盒知識書庫。

## 結構

- `data/`：文獻筆記，包含全球政策、系統性回顧、跨國案例、質性研究、台灣研究與數位健康研究。
- `note/`：可獨立重組的永久筆記，每篇聚焦一個核心主張。
- `idea/`：由研究與永久筆記延伸出的實作構想。
- `term/`：概念定義與中英文維基百科連結。
- `moc/`：主題概念地圖，附 Mermaid 關係圖。
- `Community_health_worker.md`：全書導讀與建議閱讀路徑。

所有檔名均採中文結論式標題，無編號。筆記以 Obsidian 相容的 Obsidian 雙向筆記連結 串連；根目錄導讀連結所有筆記，各筆記亦回鏈至導讀。

## 使用建議

1. 將解壓後的 `Community_health_worker` 資料夾放入 Obsidian vault。
2. 先閱讀根目錄導讀，再從 `moc` 的概念圖選擇主題。
3. 文獻筆記記錄來源、方法與可用結論；永久筆記整理可跨情境重組的主張；靈感筆記則提出可測試的制度或社區行動。
4. 外部連結為公開來源入口；部分期刊全文可能受存取限制。

資料整理日期：2026-11-24。此書庫是研究型導讀與知識整理，不構成臨床指引或政策法律意見。
