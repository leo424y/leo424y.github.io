# Emotional_labor

這是一套以 Markdown 與 Obsidian／Logseq 風格 wikilinks 建立的情緒勞動知識庫。

- `Emotional_labor.md`：全書導讀與閱讀路徑
- `data/`：24 則文獻筆記，附原始來源連結
- `note/`：24 則永久筆記，每張卡片聚焦一個可重組的主張
- `idea/`：11 則靈感筆記，提出延伸思考與可執行行動
- `term/`：19 則概念定義，附中／英／日文維基百科相關連結或搜尋入口
- `moc/`：4 張概念地圖，含 Mermaid 關係圖

總計 83 個 Markdown 筆記檔（不含本說明，包含根目錄導讀）。

## 使用方式

將整個資料夾放入 Obsidian、Logseq 或支援 `[[wikilinks]]` 的 Markdown 環境。資料夾分類依照需求採用 `data / note / idea / term / moc`。

## 研究範圍與限制

以情緒勞動社會學為主，兼及職場心理學、照顧研究、移工研究、種族與性別研究及演算法管理。部分資料為橫斷式研究或單一場域個案，請依各文獻筆記中的方法限制解讀。
