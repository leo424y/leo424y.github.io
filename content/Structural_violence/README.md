
# Structural_violence 知識書庫

- `data/`：文獻筆記，記錄來源、核心論點、研究限制與延伸閱讀。
- `note/`：永久筆記，每張卡片聚焦一個可獨立重組的主張。
- `idea/`：靈感筆記，從概念與研究推導延伸問題及可實踐行動。
- `term/`：概念筆記，提供定義、中英文維基百科條目與概念連結。
- `moc/`：概念地圖，以 Mermaid 呈現主要關係。
- `Structural_violence.md`：全書導讀、論旨、閱讀路徑與所有卡片索引。

## 編輯原則

1. 檔名採中文結論式標題，檔案內不重複標題。
2. 每卡包含內容、`思與行`、`參考`，並以雙中括號內部連結串接卡片。
3. 文獻摘要以來源可支持的範圍為限；質性個案不當作普遍代表，統計關聯不直接寫成因果。
4. 外部來源連結以 DOI、期刊、政府或出版社頁面為優先；部分頁面可能需機構訂閱。
5. 本書是研究導讀與知識卡片集，不取代原始論文、正式報告或受影響社群的一手聲音。
