# Pāramitā 知識書庫

本資料夾可直接作為 Obsidian Vault 的內容來源，或將其子資料夾合併至現有知識庫。

- `Pāramitā.md`：全書導讀、閱讀路徑與完整索引。
- `data/`：文獻筆記，包含學術研究、經典、註釋與當代教學資料；每篇均附來源連結。
- `note/`：單一概念的永久筆記，並以 wikilinks 交叉連結。
- `idea/`：由永久筆記延伸出的實踐靈感與行動構想。
- `term/`：概念定義、互相連結及中文／英文維基百科參考條目。
- `moc/`：概念地圖，含 Mermaid 關係圖。

## 使用提醒

1. 本書區分上座部巴利註釋傳統的十波羅蜜與大乘梵文系統擴展出的十波羅蜜，兩者不可混為一談。
2. 文獻筆記中的學術摘要是導讀性整理，重要論點請回到原文核對；經典、註釋及現代研究亦應分層閱讀。
3. Mermaid 圖可在支援 Mermaid 的 Markdown／Obsidian 環境中呈現。
4. 部分術語的維基百科連結指向相關條目或同一主題的概覽條目，作為快速入口，不取代學術來源。
