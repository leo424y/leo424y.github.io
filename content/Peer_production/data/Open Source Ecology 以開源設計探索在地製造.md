Open Source Ecology 的 Global Village Construction Set 設想一套可自行製作、模組化且低成本的工業機具，將設計、圖面與製造知識公開，讓不同地方能依當地材料和技能進行製作與改良。該組織的網站也呈現計畫成熟度並不一致：開源設計概念不代表所有機具都已達到可量產或可普遍複製的程度。

## 思與行
* 硬體公地需要把原型、成熟產品、維護責任和資金需求清楚區分。
* 評估是否真的在地化時，追問材料、能源、工具、技術人力與安全規範是否可取得。
