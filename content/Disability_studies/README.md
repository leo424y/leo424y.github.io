# Disability_studies 知識書庫

本資料夾以 Markdown 與 Obsidian 風格 wikilinks 編寫。根目錄 `Disability_studies.md` 是全書導讀；`data` 保存來源筆記，`note` 保存永久筆記，`idea` 保存延伸行動，`term` 保存概念定義，`moc` 保存 Mermaid 概念地圖。

筆記中的外部來源均提供可點擊連結。研究來源跨越國際組織、學術出版社、期刊、倡議組織與障礙者第一人稱敘事。對機構報告與政治倡議，請留意其資料範圍與立場；對統計估計，請同時檢查定義與測量方法。

本版依 2026-11-20 可取得資料整理。台灣第三次 CRPD 國際審查的結論性意見預定 2026-11-22 公布，相關筆記已明確標示當時狀態，之後應以正式文件更新。
