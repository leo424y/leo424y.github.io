Washington Group Short Set on Functioning（WG-SS）是為人口普查與大型調查設計的六題功能題組，涵蓋視覺、聽覺、行走、認知、自我照顧及溝通。它以功能困難而非直接詢問診斷作為測量入口，有助於跨國比較、辨識在不利環境下較可能遭遇參與限制的人群。

Washington Group 明確說明，短版題組不是完整障礙盛行率工具，也不適合直接決定服務資格；它未充分涵蓋所有心理社會功能困難、疼痛、疲勞及某些間歇性經驗。更完整的 Extended Set 可增加相關面向。測量設計的簡潔性提升可操作性，同時也會決定哪些人容易被看見。

## 思與行
* 讀取國際統計時，先確認使用 WG-SS、Extended Set 或其他定義；不要將不同工具產生的比例直接混用。
* 規劃地方調查時，除可比題組外，可增加當事人參與設計的補充問題，並交代其可比性限制。
