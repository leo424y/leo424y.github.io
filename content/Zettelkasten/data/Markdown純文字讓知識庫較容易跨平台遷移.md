### 簡述

Obsidian 官方說明指出，筆記以本機純文字 Markdown 檔案保存，使用者可離線使用，也較容易在需要時轉換到其他應用程式。官方匯入說明列出從 Notion、OneNote、Evernote、Roam Research、Logseq 等工具遷移的方式。這些說明屬於產品文件，說明的是格式與匯入能力，不等於第三方長期保存保證。

使用純文字不代表資料自動安全：仍需管理備份、附件、連結路徑、外掛依賴與同步衝突。相較於把資料鎖在單一平台，Markdown 能降低部分格式封閉風險，但不能取代完整的保存策略。

### 思與行

* 每季抽樣將幾個筆記檔複製到另一個 Markdown 編輯器，測試內容與連結是否仍能閱讀。
* 對附件使用穩定的相對路徑，並備份整個資料夾，而不只是 Markdown 檔案。
* 保留原始檔案與匯出版本，不把雲端同步誤認為備份。
