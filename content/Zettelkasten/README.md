# Zettelkasten

## 全書導讀

本書把 **Zettelkasten（卡片盒筆記法）** 視為一種長期思考基礎設施：透過短而完整的筆記、清楚的來源脈絡、具解釋力的連結與少量索引入口，讓閱讀、觀察與對話能在未來重新組合，逐步形成可檢驗的主張與寫作成果。

它不是「只要把筆記拆小就會有創意」的秘訣，也不是某一款軟體的功能清單。盧曼的卡片盒提供了重要歷史案例，但它是一個跨越數十年、依靠索引和交叉引用維護的研究遺產。現代使用者可從中學習設計原則，不必複製其卡片數量、分類或工作節奏。

本書的核心主張是：**筆記的價值不在收藏量，而在能否把來源轉化為自己的主張，並透過可理解的關係連結，支持下一次思考、寫作與行動。**

## 全書架構

* `data/`：文獻筆記，記錄 Zettelkasten 史料、學術研究、工具文件與跨文化比較材料。
* `note/`：永久筆記，從多個來源綜合出可獨立使用的觀點。
* `idea/`：靈感筆記，將方法延伸成可以實際試驗的思考與行動。
* `term/`：概念筆記，定義核心術語並建立概念間連結。
* `moc/`：索引地圖，提供歷史、工作流、數位工具、集體知識與概念導航。

## 建議閱讀路徑

### 第一路徑：先理解歷史，再理解方法

從 [[卡片盒的歷史譜系與跨文化比較]] 開始，讀 [[盧曼的卡片盒是長期演化的研究系統而非靈感魔法]] 與 [[盧曼的九萬張卡片是跨越數十年的研究遺產]]。接著比較歐洲 commonplace book、中國宋代筆記、日本閱讀文化，以及非洲、拉丁美洲與韓國的知識保存案例。這條路徑讓讀者理解：Zettelkasten 有其特定歷史，但知識整理並非歐洲單一傳統的專利，不同地方也發展出不同的媒介與社群實踐，包含南亞的口述／手稿／印刷傳承，以及原住民族資料治理對開放資料的補充。

### 第二路徑：學會把材料轉成自己的想法

閱讀 [[從捕捉到寫作的卡片盒工作流]]，依序理解 [[靈感筆記]]、[[文獻筆記]]、[[永久筆記]]、[[原子筆記]]、[[關係式連結]] 與 [[索引]]。特別留意 [[文獻筆記保存來源脈絡而永久筆記負責形成自己的主張]]：來源摘記與個人推論應該互相連結，但不能混為一談。

### 第三路徑：避免方法崇拜

閱讀 [[筆記品質來自加工與回想而不是抄錄數量]]、[[Zettelkasten不一定適合短期一次性研究任務]] 與 [[卡片盒應服務問題與寫作而不是收藏數量]]。原子筆記不是越短越好，連結也不是越多越好；真正重要的是能否形成可理解、可查核、可重用的知識。

### 第四路徑：把個人系統放回社會脈絡

閱讀 [[個人筆記集體共創與知識倫理]]。非洲口述傳統、拉丁美洲參與式知識生產、韓國地方檔案與數位社會註釋提醒我們：知識可能屬於關係、社群與特定情境。個人筆記庫不能自動取得公開或再利用他人知識的權利。

### 第五路徑：建立能長期使用的數位環境

閱讀 [[數位工具資料可攜性與長期保存]]，理解 Markdown、備份、附件、連結與遷移測試。工具應可替換，核心知識應盡量保持可讀。

## 核心原則

1. **一張卡片承載一個完整主張**：依可獨立理解程度拆分，不以字數為唯一標準。
2. **用自己的語言加工**：永久筆記要能表達作者自己的理解，並標示證據與限制。
3. **連結必須有理由**：寫出支持、反駁、類比或限制等關係，避免裝飾性連結。
4. **來源與推論分層**：文獻筆記保留來源脈絡，永久筆記建立可重用主張。
5. **索引提供入口**：MOC 是地圖，不必複製整個筆記庫。
6. **方法服務任務**：短期工作可以輕量處理，長期研究才值得持續維護網絡。
7. **尊重社群與情境**：不是所有知識都適合拆解、公開或個人化。
8. **保障長期可讀性**：使用開放格式、備份與定期遷移測試。

## 使用與維護建議

* **新增文獻**：先放入 `data/`，記錄原始來源、研究方法、主要發現與限制。
* **形成觀點**：只有當材料轉化成自己能解釋的主張時，才新增到 `note/`；每張卡片都要有來源或推理脈絡。
* **捕捉靈感**：先放入 `idea/`，每週回顧一次，決定升級、修改或刪除。
* **整理概念**：新詞彙若有穩定定義與多個連結，再建立 `term/` 詞條。
* **維護入口**：每次新增一組重要筆記，只更新最相關的 MOC，避免所有索引變得臃腫。
* **檢查品質**：每季抽查斷鏈、孤立筆記、來源失效與跨平台可讀性。

## 本書的範圍與限制

本書整理的是可公開查閱的研究、機構資料與方法文件，並非完整的全球田野調查。不同地區的案例用來比較知識保存的媒介、參與方式與倫理問題，不代表那些傳統都採用 Zettelkasten。關於筆記對記憶與創造力的效果，現有材料多屬一般筆記研究或方法論討論，不能直接推論 Zettelkasten 對每個人都有相同效益。

因此，建議把本書當成可持續修訂的研究起點：新增資料時保留來源與限制，遇到相反證據時建立修正筆記，而不是追求一套永遠不變的標準答案。
