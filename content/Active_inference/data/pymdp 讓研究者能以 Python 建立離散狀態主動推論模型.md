pymdp 是以 Python 實作離散狀態主動推論與部分可觀測馬可夫決策過程的開源套件。它能協助研究者建立生成模型、執行推論與政策選擇，並與主動推論的逐步教程互相參照。程式套件讓模型較容易重製，但使用現成程式碼不會自動保證模型假設合理；研究者仍須理解矩陣、先驗、參數與資料生成過程。

## 思與行
* 從官方教程的小型任務開始，保留版本、參數和環境設定。
* 用合成資料做參數恢復與模型檢查，再考慮真實資料。
