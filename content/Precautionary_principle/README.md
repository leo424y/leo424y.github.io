# Precautionary_principle 知識書庫

主題：預警原則（Precautionary Principle）

本書庫以卡片盒筆記法整理，包含文獻來源、永久筆記、靈感筆記、概念定義、概念地圖與根目錄導讀。

- `data/`：來源導讀卡，含原始文件／論文連結與批判性摘要。
- `note/`：單一概念的永久筆記，連結其他筆記並形成綜合觀點。
- `idea/`：延伸思考與可實踐的行動提案。
- `term/`：概念定義、雙向概念連結及中英文維基百科參考。
- `moc/`：概念地圖，使用 Mermaid 關係圖。
- `Precautionary_principle.md`：全書導讀與建議閱讀路徑。

所有筆記均為 UTF-8 Markdown。內部連結使用 Obsidian／Logseq 相容的 `[[wikilinks]]`。研究截點：2026-11-24。
