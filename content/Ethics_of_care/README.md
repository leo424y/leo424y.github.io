# Ethics_of_care 書庫

本資料夾以 Markdown 與 Obsidian wikilink 編寫。

- `data/`：研究與書籍來源卡，附原始來源連結。
- `note/`：單一論點的永久筆記，連結研究來源與概念。
- `idea/`：從理論推進到日常、社群與制度實踐的靈感筆記。
- `term/`：核心概念定義，附中文／英文維基百科連結或搜尋入口。
- `moc/`：以 Mermaid 繪製的概念地圖。
- `Ethics_of_care.md`：全書導讀與建議閱讀路徑。

研究範圍以可公開查閱的學術百科、出版社資料、期刊摘要、機構政策文件與書目頁為主。部分學術出版品可能需要機構訂閱才能取得全文；筆記依據可見的摘要、書目資訊與公開內容撰寫，不將摘要等同全文。跨文化概念保留其語境差異，避免將儒家仁、Ubuntu、whanaungatanga 與女性主義照顧倫理視為完全相同。
