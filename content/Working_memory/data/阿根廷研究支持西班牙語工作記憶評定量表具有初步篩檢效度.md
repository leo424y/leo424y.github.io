Vernuccia、Gallia 與 Andrés 於 2020 年分析西班牙語版 Working Memory Rating Scale 在拉丁美洲兒童中的心理計量特性。研究樣本為約 8.5 至 12.3 歲兒童，結合教師評定、客觀工作記憶測量與學業技能指標。西班牙語量表得分與客觀工作記憶及學業測量呈負相關，單因素模型有可接受的適配度，完整量表比五題短版表現更好。

這項研究支持該量表在其樣本中的初步篩檢用途，不代表它可取代正式評估、診斷，或不經檢驗地應用於所有西班牙語國家。教師評定、客觀測驗與學業表現是不同資料來源，應互相補充。

## 思與行
* 將教師日常觀察納入認知評估，可以補足單次實驗室測驗，但必須檢查評定工具的語言和文化適切性。
* 跨國使用量表時，重新驗證信度、效度與測量等值性，不直接照搬原版常模。
