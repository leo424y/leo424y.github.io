工作記憶的核心著作可以從三種互補角度閱讀。Alan Baddeley 的 *Working Memory, Thought, and Action*（2007）回顧多成分工作記憶模型的發展，討論模型支持證據及替代取徑，適合作為整體理論入口。Nelson Cowan 的 *Working Memory Capacity*（2005）專注於容量限制的解釋，整理項目數、組塊、干擾與時間等不同假說，適合深入理解「容量」為何不是簡單固定數字。Susan Gathercole 與 Tracy Packiam Alloway 的 *Working Memory and Learning: A Practical Guide for Teachers*（2008）則把研究連到學校學習，討論工作記憶與讀寫、數學、發展差異及課堂支持策略。

三本書的用途不同：Baddeley 提供模型史與理論全景，Cowan 聚焦容量限制的機制爭論，Gathercole 與 Alloway 著重教育現場的辨識和支持。它們出版年份較早，適合建立基礎與理解研究史；至於當代神經機制、訓練效果與評估工具，仍應搭配較新的原始研究和統合分析，不能把書中的所有實務建議當成現行臨床或教育標準。

## 思與行
* 先讀 Baddeley 建立模型架構，再讀 Cowan 比較容量限制的不同解釋，最後讀 Gathercole 與 Alloway 思考如何把理論轉成課堂支持。
* 閱讀時將「理論模型」、「實驗測量」與「教學建議」分開標記，避免把模型中的功能元件直接當成教學處方。
* 將三本書與[[工作記憶模型把暫存與注意控制拆成可互動的多個成分]]、[[工作記憶的核心容量通常比七個項目更接近三至五個組塊]]及[[教學應減少與學習目標無關的工作記憶負荷]]交叉閱讀。
