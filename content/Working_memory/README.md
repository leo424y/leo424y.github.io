# Working_memory 專題書庫

- `Working_memory.md`：全書導讀、主張、閱讀路徑及全部卡片索引。
- `data/`：文獻筆記，包含原始論文、統合分析、研究者訪談與方法資料。
- `note/`：永久筆記，每張卡片聚焦一個可獨立重組的主張。
- `idea/`：靈感筆記，從研究與永久筆記延伸至觀察、設計和行動。
- `term/`：概念定義與中英文維基百科入口。
- `moc/`：概念地圖，含 Mermaid 關係圖。

筆記使用中文結論式檔名；文獻與永久／靈感筆記依序包含正文、`思與行`、`參考`。連結以資料夾路徑表示，適合支援 Markdown wikilink 的知識管理工具。
