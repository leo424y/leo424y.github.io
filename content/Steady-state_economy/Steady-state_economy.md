# 穩態經濟：在生態限度內實現公平與繁榮

穩態經濟（Steady-State Economy）是一種將經濟重新放回生態系統之中的制度構想。它不把 GDP 持續增加視為經濟政策的最終目的，而是關注經濟的物質與能源規模是否落在地球生態系統可承受的範圍，並進一步追問：在總量受到限制時，資源如何公平分配、生活如何持續改善，以及制度如何維持就業、公共服務與民主自由。

本書以 Herman Daly 的生態經濟學為理論主軸，結合宏觀經濟模型、去耦合研究、後成長辯論、福祉指標和全球不同地區的政策案例。它不是把所有相近思潮合併成一套理論，而是整理彼此的共通問題、分歧與轉型可能。

## 全書主張

1. **經濟是生態系統中的子系統。** 經濟需要材料、能源與環境吸納能力，因而存在物理規模的限制。
2. **規模、分配、配置必須分開處理。** 市場效率不會自動設定生態上限，也不會自動實現分配正義。
3. **穩態不等於停滯。** 人口與人造資本存量的長期穩定，並不妨礙知識、制度、照護、文化與生活品質持續發展。
4. **福祉與生態總量要一起衡量。** 超越 GDP 的指標很重要，但需要同時監測材料、能源、土地、碳與生物多樣性。
5. **轉型必須公平且民主。** 高消耗社會應承擔較大的減量責任，仍有基本需求缺口的社會需要發展空間；工人、弱勢群體與地方社群必須參與決策。

## 研究使用提醒

- 穩態經濟、去成長、後成長、無成長偏好、福祉經濟與循環經濟有交集，但不是同義詞。
- 全球政策案例多半是局部制度工具或相鄰理念，不宜宣稱為穩態經濟的完整實作。
- 所有環境指標都要註明核算邊界、資料年份與是否包含進口隱含足跡。
- 模型是檢驗假設的工具，不是未來預言；政策是否可行仍取決於政治、文化、制度與分配條件。
- 本書庫以可公開查閱的學術論文、官方研究和出版資訊為起點；後續應持續補入全球南方與地方社群的第一手訪談、原住民族自述及非英語文獻。
