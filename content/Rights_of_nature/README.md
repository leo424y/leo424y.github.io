# Rights_of_nature 知識書庫

本資料夾以卡片盒筆記方式整理自然權利（Rights of Nature），包含文獻與案例、永久論點、靈感與行動、概念定義、概念地圖及根目錄導讀。

## 使用方式

1. 先閱讀 `Rights_of_nature.md`，它連結全部筆記，是本書的導航頁。
2. `data/` 保存法規、判決、研究和書籍的文獻筆記；`note/` 保存可獨立重組的論點；`idea/` 保存延伸思考與行動方案。
3. `term/` 是概念定義與雙向概念連結；`moc/` 是主題關係地圖，包含 Mermaid 圖。
4. 檔名採中文結論式標題，不編號；正文使用雙方括號內部連結，可匯入支援 wikilink 的知識管理工具。

## 範圍與方法

* 以全球不同法域為比較範圍，納入南美洲、大洋洲、南亞、北美、歐洲、非洲及國際／區域制度。
* 優先採用官方法規、法院判決、政府資訊、學術期刊與大學出版社；民間倡議資料僅在其本身為研究對象或原始宣言時使用。
* 明確區分憲法、法律、司法判決、地方決議、聯合國決議及民間宣言的法律效力。
* 研究截止日期：2026-11-26。法律現況可能持續變動，正式使用前請核對來源原文與最新修法。
* 這是學術與知識整理，不構成法律意見。
