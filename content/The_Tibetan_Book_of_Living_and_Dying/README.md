# The Tibetan Book of Living and Dying — 知識書庫

本資料夾依卡片盒筆記法分為：
- `data/`：文獻與來源摘要（含可點擊來源連結）
- `note/`：單一觀點的永久筆記
- `idea/`：延伸思考與可實踐行動
- `term/`：概念定義與中英文維基百科條目
- `moc/`：概念地圖與 Mermaid 關係圖
- `The_Tibetan_Book_of_Living_and_Dying.md`：總導讀、閱讀路徑與全庫索引

建議以 Obsidian 或 Logseq 開啟，並確認 Mermaid 圖表支援已啟用。筆記中的 `[[wikilinks]]` 以檔名為連結目標。
