# Source note

Fiona Kumari Campbell 將 ableism 的分析焦點從「障礙者受到什麼歧視」推向「社會如何生產健全性、正常性與可被認可的能力」。能力主義不只是一個人對障礙者抱持負面態度，也是一套把特定身體、感官、認知、情緒與生產能力設定為標準，再以此安排制度、空間、語言與資源的權力關係。

本書的重要貢獻，是讓研究者不再把「健全」當作自然、透明且不需解釋的背景，而是研究它如何被規範、維持與獎勵。書中也討論內化能力主義、對障礙的預防／修補想像，以及科技如何同時帶來支持與新的常態化壓力。

## 思與行
* 盤點一個組織中「理想成員」的隱含規格：能否久坐、快速閱讀、準時、持續社交、口語表達、穩定產出？
* 分析制度時，同時問「誰被排除」與「哪種能力被建構為理所當然」。
