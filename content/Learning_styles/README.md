# Learning_styles 書庫

這是一套以繁體中文撰寫、可直接匯入 Obsidian 的 Markdown 卡片盒書庫。

## 使用方式

1. 將整個 `Learning_styles` 資料夾解壓縮至 Obsidian vault。
2. 開啟根目錄的 `Learning_styles.md` 作為導讀。
3. `wikilinks` 可在 Obsidian 中直接建立雙向連結；資料夾中的同名檔案即為連結目標。
4. Mermaid 圖可在支援 Mermaid 的 Markdown 預覽器中檢視。

## 結構

- `data/` 文獻筆記
- `note/` 永久筆記
- `idea/` 靈感筆記
- `term/` 概念定義
- `moc/` 概念地圖

## 編輯原則

每張文獻、永久與靈感卡片聚焦一項主要概念，採用「內容 → 思與行 → 參考」結構；檔名即標題。文獻筆記保留原始來源連結與研究限制。文化案例只用來說明特定社群、地區或研究樣本，不將其推廣為固定的國族性格或普遍學習類型。
