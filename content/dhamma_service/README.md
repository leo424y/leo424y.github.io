# 內觀法工 Dhamma Service 經驗｜Obsidian 書籍型知識庫

這是一套繁體中文 Markdown 知識庫，可直接解壓後以 Obsidian 開啟資料夾。

## 資料夾

- `00_序與導覽`：序、目錄、概念索引。
- `01_文獻筆記`：官方規範、服務者見證、研究與背景文獻。
- `02_永久筆記`：從多份材料歸納的單一論點。
- `03_概念筆記`：核心名詞與分析概念定義。
- `04_靈感筆記`：延伸問題、觀察方法與可執行行動。

## 使用方式

解壓縮後，在 Obsidian 選擇「開啟資料夾作為倉庫」，選取本資料夾。筆記以 `雙向連結` 互相引用；目錄連結所有筆記，概念索引整理概念筆記及提及它們的其他筆記。

## 編輯原則與限制

- 檔名即結論式標題；筆記內不另加標題或屬性。
- 每張卡片聚焦一個主張或概念，並保留「延伸思考與行動」「脈絡與依據」兩節。
- 來源類型已盡可能區分為官方政策、個人見證與學術研究。
- 部分個人見證為匿名或自動翻譯內容，不能視為代表性調查。
- 各中心服務資格與規則可能更新，實際申請請以當地中心最新公告為準。
