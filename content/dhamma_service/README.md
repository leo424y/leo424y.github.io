# Dhamma_service｜法的服務書庫

這是一個可直接匯入 Obsidian 的 Markdown 資料夾。

- `Dhamma_service.md`：全書導讀、閱讀路徑與索引
- `data/`：文獻筆記（官方文件、第一人稱心得、研究、論文與書籍）
- `note/`：永久筆記（單一論點、跨來源歸納與交叉引用）
- `idea/`：靈感筆記（可延伸的研究、實踐與行動）
- `term/`：概念定義
- `moc/`：概念地圖（含 Mermaid 關係圖）

所有內部連結使用 Obsidian Wikilinks。部分學術來源僅能取得摘要或書目資訊，已在對應文獻筆記中標示限制。
