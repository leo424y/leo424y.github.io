# Critical_thinking

這是一個 Obsidian 相容的 Markdown 書庫，主導讀檔為 [[Critical_thinking]]（檔案：`Critical_thinking.md`）。

| 資料夾 | 用途 | 數量 |
|---|---|---:|
| `data/` | 文獻、研究、訪談、框架與書籍來源筆記 | 21 |
| `note/` | 歸納後的永久筆記 | 16 |
| `idea/` | 延伸思考與可執行的靈感 | 9 |
| `term/` | 概念定義與雙向連結 | 26 |
| `moc/` | Mermaid 概念地圖 | 4 |

使用 Obsidian 開啟整個 `Critical_thinking` 資料夾即可。建議先從 `Critical_thinking.md` 的閱讀路徑開始。
