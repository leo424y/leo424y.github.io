# Playback Theatre｜Obsidian 研究書庫

將本資料夾整體解壓縮後，以 Obsidian 開啟 `Playback-Theatre-Obsidian` 資料夾即可使用。

- `data/`：文獻筆記，包含學術研究、學位論文、機構案例與國際實務資源。
- `note/`：永久筆記，每篇聚焦一個可重組的論點。
- `idea/`：靈感筆記，將論點轉成可試驗的思考與行動。
- `term/`：概念定義與互相連結。
- `moc/`：概念地圖，導覽不同主題群。
- `Playback Theatre.md`：根目錄導讀、閱讀路徑與全筆記索引。

本文獻資料整理截止 2026-11-01。外部連結的可用性與期刊開放權限可能改變；請以原始來源為準。
