# Playback Theatre 書庫

- `data/`：文獻筆記，整理研究、書籍、倫理文件與不同地區的實務案例。
- `note/`：永久筆記，將可重組的單一觀點拆成原子卡片。
- `idea/`：靈感筆記，提出可延伸的研究、活動與行動設計。
- `term/`：概念定義，附有回鏈至相關概念。
- `moc/`：概念地圖，以 Mermaid 呈現核心關係。
- `Playback_Theatre.md`：全書導讀、閱讀路徑與完整索引。

## 使用方式

建議以 Obsidian 開啟此資料夾，保留資料夾結構與 Markdown wikilinks。概念地圖使用 Mermaid 語法。

## 研究範圍與限制

本版主要以可公開存取的學術論文、機構出版資料、出版商書目與 IPTN 實務者期刊為基礎。資料來源類型並不相同：學術研究用於討論研究設計與結果；機構網站用於整理組織自述與服務；實務者文章用於呈現在地經驗與反思。個案不能代表整個國家，主觀回饋也不能直接等同臨床療效。部分書籍可能需購買或透過圖書館取得全文。
