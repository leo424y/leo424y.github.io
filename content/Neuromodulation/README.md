# Neuromodulation 書庫

- `Neuromodulation.md`：全書導讀與建議閱讀路徑
- `data/`：文獻筆記（研究、指南、政策、患者經驗）
- `note/`：永久筆記（經整理的可重用觀點）
- `idea/`：靈感筆記（延伸思考與行動）
- `term/`：概念定義與中英文維基百科入口
- `moc/`：概念地圖與 Mermaid 關係圖

所有筆記均以 UTF-8 Markdown 儲存。卡片內的雙向維基連結以檔名為連結目標，可供 Obsidian、Logseq 等支援雙向連結的工具使用。

資料整理基準日：2026-11-20。這是知識整理材料，不是個別醫療建議。
