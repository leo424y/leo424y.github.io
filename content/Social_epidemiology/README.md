# Social_epidemiology

這是一份以繁體中文編寫的社會流行病學 Markdown 知識書庫，依卡片盒筆記方式分為：

- `data/`：文獻與研究來源筆記，附原始來源連結。
- `note/`：可獨立引用的永久筆記，包含思與行、參考與內部連結。
- `idea/`：由概念延伸的研究、社區與政策行動構想。
- `term/`：概念定義與中英文維基百科搜尋連結。
- `moc/`：重要概念關係圖（Mermaid）。
- `Social_epidemiology.md`：全書導讀、論證脈絡與建議閱讀路徑。

建議使用支援 `wikilinks` 與 Mermaid 的 Markdown 編輯器（例如 Obsidian）。外部文獻連結依各研究者與出版機構頁面提供；引用前請再次核對最新版本、研究設計與適用範圍。此書庫是研究導讀與知識整理，不構成醫療診斷或政策效果的單一證據。
