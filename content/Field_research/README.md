# Field Research — Markdown Knowledge Book

這是一套可在 Obsidian、Logseq 或一般 Markdown 編輯器中使用的田野研究知識庫。

## 結構與筆記數量

- `Field_research.md`：全書導讀、閱讀路徑與筆記入口
- `data/`：23 篇文獻筆記，記錄來源、研究貢獻與限制
- `note/`：34 篇永久筆記，以單一主張為單位並交叉引用
- `idea/`：14 篇靈感筆記，將概念轉成延伸思考與可執行行動
- `term/`：35 篇概念筆記，提供定義、雙向概念連結與中英文維基百科入口
- `moc/`：6 張概念地圖，包含 Mermaid 關係圖與筆記索引
- 全部共 114 個 Markdown 檔案（含導讀與本說明）。

## 使用方式

1. 將 ZIP 解壓縮。
2. 將 `Field_research/` 資料夾加入 Obsidian 或 Logseq。
3. 由根目錄 `Field_research.md` 開始，或直接開啟 `moc/` 中的概念地圖。
4. 新增筆記時沿用現有的檔名與 wikilink 方式，並保留資料來源及田野倫理限制。

## 內容範圍

本書以跨學科田野研究為主軸，涵蓋質性研究、民族誌、參與觀察、訪談、田野筆記、參與式行動研究、原住民族與去殖民方法、數位與感官田野、多點民族誌，以及生態監測、公民科學與社會生態研究。案例與文獻涉及美洲、歐洲、亞太與原住民族研究脈絡，但並非全球所有傳統與學科的完整代表。

## 注意

- 本知識庫是研究方法導讀與知識整理，不取代研究倫理審查、在地法律或社群自身的資料治理規範。
- 維基百科連結用於概念初步導讀；學術論證應優先回到 `data/` 中的原始文獻或專業機構指引。
