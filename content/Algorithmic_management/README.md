# Algorithmic_management 書庫

- `Algorithmic_management.md`：全書導讀、論點、建議閱讀路徑與索引。
- `data/`：文獻、政策、研究、訪談與代表性書籍的來源筆記。
- `note/`：可獨立重組的永久筆記，每張卡片聚焦一個概念。
- `idea/`：由研究與永久筆記延伸出的研究、設計及行動提案。
- `term/`：概念定義、雙向概念連結與中英文維基百科入口。
- `moc/`：概念地圖與 Mermaid 關係圖。

所有內部連結使用 Obsidian／Logseq 常見的 Obsidian／Logseq 雙中括號筆記連結格式 格式。外部來源在 `data/` 中以原始論文、機構或出版社連結為主。資料截至 2026-11-11；新法規與報告請回到官方頁面查核最新版本。
