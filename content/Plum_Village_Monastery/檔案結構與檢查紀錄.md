# 檔案結構與檢查紀錄

本書庫以 Markdown 與 wikilink 組成，檔名不編號；每則文獻、永久與靈感筆記均包含「思與行」及「參考」。概念筆記附中文維基搜尋與英文維基連結；概念地圖以 Mermaid 表達關係。

## 檔案數量
* `data/`：20 篇
* `note/`：29 篇
* `idea/`：11 篇
* `term/`：29 篇
* `moc/`：5 篇

## 檢查項目
* 根目錄導讀連結全部 data、note、idea、term、moc 筆記。
* 所有 wikilink 均能解析至本書庫內的 Markdown 檔案。
* note 與 idea 之間有交叉引用；MOC 連結主要 term 與其他 MOC。
* 所有檔案皆為 UTF-8 Markdown。
* 文獻資料標明來源連結；研究樣本、日期與限制已在相應卡片說明。
* 網頁數據與費用資料可能變動，請以官方最新頁面為準。
