# Cultural_appropriation

本資料夾是「文化挪用：權力、文化流動與共同創造」的 Markdown 知識書庫。

## 資料夾結構

- `data/`：文獻筆記，保留來源連結、書目資訊與閱讀思考。
- `note/`：永久筆記，以單一結論命題整理跨來源見解。
- `idea/`：靈感筆記，將研究轉成延伸問題、設計與行動。
- `term/`：概念定義，附中英文維基百科入口並互相連結。
- `moc/`：概念地圖，包含 Mermaid 關係圖與雙向連結。
- `Cultural_appropriation.md`：全書導讀、閱讀路徑與全部筆記索引。

## 使用方式

可直接匯入 Obsidian、Logseq 或其他支援 Markdown 與 `[[wikilink]]` 的知識管理工具。Mermaid 圖需由支援 Mermaid 的閱讀器渲染。外部來源連結依各出版者／機構頁面為準。

## 研究邊界

這是一份可持續擴充的跨區域研究初稿，並非完整的全球民族誌或法律意見。特別是涉及社群內部代表性、神聖知識與現行法律的議題，應優先回到來源社群及官方制度文件核實。
