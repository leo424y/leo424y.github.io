# Peer_support 專書資料夾

這是一套以 Markdown 與 Obsidian／Logseq 風格 wikilinks 編寫的同儕支持知識庫。

- `data/`：21 篇文獻、政策、案例與研究筆記。
- `note/`：15 篇永久筆記，整理可跨場域重組的主張。
- `idea/`：10 篇靈感筆記，將概念延伸為可試行的行動。
- `term/`：17 篇概念定義與維基百科參考。
- `moc/`：4 張概念地圖，含 Mermaid 關係圖。
- `Peer_support.md`：全書導讀、論點、證據評讀與閱讀路徑。

研究整理日期：2026-11-28。這是主題式策展，不是完整系統性回顧；每個研究筆記均保留可回到原文的連結。
