# Social_connection 書庫

本資料夾依卡片盒筆記法整理，包含 `data` 文獻筆記、`note` 永久筆記、`idea` 靈感筆記、`term` 概念定義與 `moc` 概念地圖。根目錄 `Social_connection.md` 是全書導讀。

筆記採中文結論式標題（概念詞條以英文原詞作為檔名），各卡片盡量聚焦單一主張，並以 Obsidian／Logseq 可辨識的 wikilinks 建立連結。研究來源連結直接附於文獻筆記。

研究範圍涵蓋公共衛生、心理學、社會學、社會網絡、城市研究、數位媒介，以及非洲、日本、東南亞與拉丁美洲等文化與地方案例。觀察性研究與統合分析的關聯不等於因果證明；跨文化個案也不應被當成整個地區的代表。
