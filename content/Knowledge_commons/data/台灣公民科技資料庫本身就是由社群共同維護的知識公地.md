Civic Tech Taiwan 以專案目錄、分類、行動指引、共筆文件和開放 API 呈現臺灣公民科技社群的工作。網站公開說明資料庫由社群共同填寫，尚未補齊的欄位被當作可參與的缺口，而不是需要隱藏的瑕疵。

## 思與行
知識目錄可將缺項當作招募入口：標明需要補充的欄位、如何驗證、如何提出修正，讓資訊缺口變成具體的共同工作。
