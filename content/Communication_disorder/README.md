# Communication_disorder 書庫

本資料夾以繁體中文整理廣義溝通障礙，採卡片盒筆記法。

- `Communication_disorder.md`：全書導讀、核心論點與閱讀路徑
- `data/`：研究、政策、臨床指引、訪談與第一人稱書籍資料
- `note/`：由文獻歸納的永久筆記
- `idea/`：延伸思考與可實作行動
- `term/`：概念定義與中英文維基百科連結
- `moc/`：概念地圖與 Mermaid 關係圖

筆記採中文結論式檔名，跨筆記連結使用 `wikilinks`。研究地區、方法與資料限制盡可能標示；不同研究的盛行率及統計定義不可直接互換。
