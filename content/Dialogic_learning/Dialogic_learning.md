# 對話式學習：共同探究、差異理解與知識共創

**Dialogic Learning** 是一種把學習理解為共同探究的取向：人們透過提問、聆聽、解釋、質疑、回應與反思，讓不同觀點互相作用，並在過程中形成或修正理解。它不等於輪流發言、自由聊天或為了共識而消除差異；其核心是參與者能否彼此回應，並讓對話改變自己與群體對問題的理解。

本書把 Dialogic Learning 視為一個跨領域、跨文化的研究集合，而非單一標準化方法。其思想根源包含蘇格拉底式追問、杜威的民主教育、布伯的關係哲學、Freire 的解放教育、Bakhtin 的對話主義，以及社會文化取向的共同思考理論。當代實踐則延伸至課堂教學、兒童哲學、文學聚會、跨文化教育、社區共學與線上探究社群。

## 全書主張

1. **對話的價值不在說了多少，而在彼此是否改變了理解。** 互動若沒有接續、追問、理由與修正，就可能只是意見並列。
2. **對話需要結構，也需要開放。** 清楚的學習目標、支持性規範和主持者引導，可以保護探究空間，而不必壟斷結論。
3. **差異與異議是知識資源。** 多聲性讓隱藏前提浮現；但開放不等於所有主張都同樣可信，也不意味著可以放任羞辱或歧視。
4. **參與公平必須檢視權力。** 能發言、被聆聽、影響議題與共同決策，是不同層次的參與。
5. **方法必須在地化。** 巴西文化圈、印度學校的異議教育、南非 Ubuntu 取向、藏族口述辯論、中國課堂介入與印尼低社經課堂研究，呈現不同的對話形式與制度條件。
6. **學習成果與互動過程需要一起評估。** 概念理解、推理品質、參與分布、觀點修正、信任與行動，都可能是重要指標。

## 研究範圍與限制

本書優先收錄可辨識作者、出版資訊或機構來源的研究、原典與官方資源，涵蓋南美、北美、歐洲、南亞、東亞、非洲與東南亞案例。案例分布並不等於全球代表性；部分地區的材料較少，部分理論來源在當地有不同脈絡。對話教育的研究術語亦不一致，dialogic learning、dialogic pedagogy、dialogic teaching、dialogic instruction 與 community of inquiry 彼此重疊但不能直接互換。實證結果須依研究設計、樣本與場域解讀。

本資料庫為可持續修訂的研究底稿，不是系統性回顧或完整的全球教育史。後續擴充時，建議優先補足南亞、非洲法語區、拉丁美洲以外的原住民教育、成人與職場學習，以及線上跨國社群的長期追蹤研究。
