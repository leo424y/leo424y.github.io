# Bodily_integrity 書庫

主題：Bodily Integrity（身體完整性）

- `Bodily_integrity.md`：全書導讀與閱讀路徑
- `data/`：來源／文獻筆記，含原始連結
- `note/`：永久筆記，單卡單一論點並使用 Obsidian 雙向連結
- `idea/`：靈感筆記，將論點轉化為延伸思考與行動
- `term/`：概念定義與中英文維基百科連結
- `moc/`：概念地圖，含 Mermaid 關係圖

所有 Markdown 檔名均使用中文結論式標題，不編號。筆記間使用 `[[雙向連結]]`，可直接放入 Obsidian 等支援 wikilink 的知識管理工具。

資料範圍截至 2026-11-11。這是研究整理與閱讀入口，不構成法律或醫療意見。部分維基百科中文連結可能因條目名稱或條目存在狀態而需要人工校正；主要文獻以官方機構與出版者來源為主。
