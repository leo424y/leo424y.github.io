# 研究範圍與使用提醒

本書是截至 **2026-11-26** 的研究型整理，採取跨區域與多學科取徑。來源涵蓋同行評審論文、研究機構報告、政府法律與政策文件、國際組織指南、學者論證及相關書籍。

## 來源類型

- 研究論文與綜述：用於整理技術方法、已觀察現象及研究限制。
- 訪談與學者觀點：以受訪者立場呈現問題意識與提案，不將個人主張等同於已驗證結論。
- 國際組織與政府文件：用於比較規範原則、政策方向及法律框架。
- 批判研究與專書：用於理解偏見、權力、資料與文化代表性。
- 靈感筆記：是可實踐的提案，不代表已有實證證明其成效。

## 重要限制

本書未逐篇重現所有原始研究的完整實驗資料；文獻筆記以公開摘要、官方介紹及可取得的書目資訊進行整理。對政策文本的說明不等同於法律意見；正式合規或引用前，應查核最新官方原文。區域框架不代表該區所有國家已一致執行。維基百科連結是入門索引，不是核心證據來源。

## 資料夾

- `data/`：文獻與政策來源筆記。
- `note/`：可重組的永久概念與論點。
- `idea/`：延伸思考、試驗與行動提案。
- `term/`：概念定義與維基百科中英文入口。
- `moc/`：主題關係圖與閱讀地圖。
