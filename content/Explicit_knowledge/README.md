# Explicit_knowledge 書庫

本書庫以 Markdown 與 Obsidian 相容的 wikilinks 建立。

- `data/`：文獻筆記，含來源連結、研究脈絡與限制。
- `note/`：永久筆記，每張卡片聚焦一項可重組的主張。
- `idea/`：延伸思考與可執行的實驗。
- `term/`：概念定義與中英文 Wikipedia 條目／搜尋連結。
- `moc/`：概念地圖，使用 Mermaid 關係圖。
- `Explicit_knowledge.md`：全書導讀、論點與閱讀路徑。

建議使用支援 Mermaid 與 wikilinks 的 Markdown 筆記軟體開啟。
