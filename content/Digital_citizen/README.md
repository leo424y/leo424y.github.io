# Digital_citizen 專題庫

本資料夾以繁體中文整理 Digital citizen 主題，採卡片盒筆記結構。每張文獻、永久與靈感卡片聚焦一個可重組的主張，並以 Obsidian／Logseq 風格 wikilinks 連結其他卡片。

- 根目錄 `Digital_citizen.md`：全書導讀與閱讀路徑
- `data/`：文獻、政策、法律、研究與案例筆記
- `note/`：由來源綜合而成的永久見解
- `idea/`：可延伸成社區實驗或個人行動的靈感
- `term/`：概念定義與維基百科條目入口
- `moc/`：概念地圖與主題導航

來源涵蓋國際組織、歐洲政策、非洲網路權利倡議、巴西法律、台灣公民科技、Māori／原住民族資料治理與學術研究。統計資料均保留原始年份；政策框架與法律文件的拘束力不同，閱讀時請勿混為一談。維基百科連結若無穩定中文條目，提供搜尋入口以便進一步確認。
