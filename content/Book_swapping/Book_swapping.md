# 圖書交換：讓書本持續旅行的共享文化、社群制度與知識流通

**Book_swapping** 是一份以圖書交換為核心的研究型知識書庫，整理書籍如何在人與人之間流動，以及這種流動如何連結互惠、公共文化、社區關係、資訊可及性與文化公平。

本書不把所有分享形式混為一談，而是比較一換一、點數交換、免費取閱、捐贈、借閱、漂流與線上分散式網絡。從個人書架到街角圖書館，從大學活動到移民社群的共享書庫，核心問題都是：**書籍如何持續被閱讀，而不是只被持有？這個過程又由誰決定、誰能參與、誰負責維護？**

## 全書概述

圖書交換看似只是把讀完的書交給下一位讀者，實際上卻牽涉制度設計與社會關係。荷蘭鄰里交換研究發現，使用者每取走十本書，平均會留下約九本，顯示低監管的非貨幣交換也可能依靠社會規範維持。Seattle 的館藏研究則發現，交換書架的書種與附近公共圖書館具有互補性。澳洲研究進一步指出，街角圖書館既可能創造禮物經濟與社會資本，也可能在空間分布上偏向社經條件較有利的社區。

不同地區呈現不同形式：日本校園以輪替書架吸引學生接觸新書；日本 Book Swap Japan 採捐入後免費取用，並將閱讀與河畔活動連結；希臘案例把交換圖書館放在經濟危機與共享需求下理解；印度清奈出現由居民自發維護的街角小型圖書館。香港移民在英國建立分散式 BookShare，讓繁體中文書籍跨越城市界線流通。台灣則可見臺北市立圖書館常設「好書交享閱」、大學圖書館自由索取活動，以及台中閱讀節的短期交換活動。

這些實踐並非公共圖書館的替代方案。公共圖書館具有專業館藏、資訊服務與公共問責；民間書架則以鄰近、彈性與自發性補充生活中的閱讀入口。兩者應尋求互補，而不是將公共責任推給個別志工。

因此，本書的主要見解有四：

1. **交換制度可以很輕，但規則必須可理解。** 是否需要帶書、如何判斷書況、剩餘物資如何處理，都會影響信任與參與門檻。
2. **書籍流通也可能生產社會關係。** 書架可以成為偶遇、推薦、共同維護與弱連結的媒介，但只有嵌入日常生活並持續使用，才可能成為社會基礎設施。
3. **免費不等於公平。** 地點、語言、館藏內容、數位能力與交通條件都會影響誰能取得書籍。交換活動需要檢查是否涵蓋資源較少的社區。
4. **數量不是唯一成效。** 書種多樣性、實際可及性、讀者經驗、社群關係與維護成本，都應納入評估。
