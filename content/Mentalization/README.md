## 筆記規則

- 檔名採中文結論式標題，不另在正文重複標題。
- `data / note / idea` 均含正文、`思與行`、`參考`。
- `term` 以概念定義為主，並提供概念連結與中英文維基百科入口。
- `moc` 含簡述、Mermaid 關係圖、概念與筆記連結。
- 根目錄導讀以 `[[筆記檔名]]` 連結各資料夾筆記。
