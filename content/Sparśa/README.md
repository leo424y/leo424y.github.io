# Sparśa 書庫

本書庫以 Sparśa／phassa（觸）為主題，整合早期佛教經典、佛教論書、印度哲學、觸覺哲學與現代體感研究。

- `data/`：文獻筆記，附原典、論文或研究來源連結。
- `note/`：單一命題的永久筆記，以跨來源歸納為主。
- `idea/`：由概念延伸的實踐、研究與設計構想。
- `term/`：術語定義、雙向連結及中英文維基百科條目。
- `moc/`：重要概念地圖與 Mermaid 關係圖。
- `Sparśa.md`：全書導讀與閱讀路徑。

## 使用提醒

1. 佛教 phassa、梵語 sparśa、正理—勝論 sparśa-guṇa／saṃyoga，以及現代 touch perception 是彼此相關但不等同的概念。
2. 跨領域對照用於提出比較問題，不代表古代教理與現代神經科學可直接互譯。
3. 外部網頁可用性與版本可能變動；引用時請以原典或期刊頁面的最新版本為準。
4. Wiki 連結使用 Obsidian 相對路徑格式。
