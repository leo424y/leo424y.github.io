# Ultra-processed_food 知識書庫

本資料夾以繁體中文整理超加工食品主題，涵蓋研究文獻、永久筆記、靈感筆記、概念詞條與 Mermaid 概念地圖。主導讀為 `Ultra-processed_food.md`。

## 資料夾
- `data/`：文獻、研究、訪談與政策來源。
- `note/`：原子化永久筆記與跨領域歸納。
- `idea/`：延伸問題、行動方案與小型實驗。
- `term/`：概念定義及中英文維基百科入口。
- `moc/`：概念地圖與知識導覽。

## 使用方式
建議在 Obsidian、Logseq 或支援 Wiki 連結的 Markdown 編輯器中開啟。所有內部連結以檔名為頁面名稱。

整理基準日：2026-11-14。文獻摘要為研究導讀，不取代原始論文；來源可能有訂閱限制，研究結論應連同方法限制閱讀。
