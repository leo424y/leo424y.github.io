# Art_therapy

Obsidian-compatible Markdown knowledge book on art therapy.

- `Art_therapy.md`: Chinese guide, overview, reading path, complete index.
- `data/`: source notes with links, findings, limits, and research questions.
- `note/`: atomic permanent notes connecting evidence and concepts.
- `idea/`: practical, explicitly non-clinical experiments and project proposals.
- `term/`: concise concept definitions with wikilinks.
- `moc/`: Mermaid concept maps and navigation pages.

Open `Art_therapy.md` as the starting point. Internal references use Obsidian double-bracket links. Mermaid diagrams use fenced `mermaid` blocks.
