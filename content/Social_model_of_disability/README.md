# Social_model_of_disability

這是一份以卡片盒筆記方式整理的研究型 Markdown 知識庫。各資料夾依筆記功能分類，筆記檔名採中文結論式標題，檔案內容使用 Obsidian 相容的 雙向連結。

## 研究範圍與使用提醒

本資料庫以可公開查閱的學術論文、國際組織文件、障礙者運動材料與區域研究為起點，涵蓋英國、台灣、日本、印度、南部非洲、烏干達、拉丁美洲及原住民族觀點。它是可持續擴充的導讀與知識圖譜，不宣稱已窮盡各地文獻，也不將任何地區視為單一文化經驗。

文獻摘要以來源可支持的主要論點為主；部分來源只有摘要或機構介紹可公開取得，引用時應回到原文核對研究方法、樣本與限制。維基百科連結可作為入門導航，不取代原始文獻。

## 開啟方式

建議以 Obsidian 或其他支援 Markdown 與 wikilinks 的軟體開啟根目錄。從 `Social_model_of_disability.md` 開始閱讀；每張卡片底部均提供返回導讀的連結。
