# Cognitive_load 知識書庫

本資料夾以卡片盒筆記方式整理認知負荷，包含文獻筆記、永久筆記、靈感筆記、概念詞條、概念地圖及根目錄導讀。

- `Cognitive_load.md`：全書導讀與閱讀路徑。
- `data/`：文獻摘要與原始來源連結。
- `note/`：可獨立重組的永久筆記。
- `idea/`：由研究延伸出的實作靈感。
- `term/`：概念定義與中英文維基百科連結。
- `moc/`：概念關係圖與導覽。

## 使用提醒

1. 文獻摘要以公開摘要、出版社頁面、資料庫紀錄或可取得全文為基礎；請由連結回到原文確認細節。
2. 認知負荷理論的三分類在不同年代有不同表述；本庫已將增生負荷的理論地位標示為有爭議，不應跨研究直接比較量值。
3. 2026 年新近研究只作為特定情境的補充證據；單一國家、學科或質性訪談不能代表全球學習者。
4. 維基百科連結是概念入口，不取代學術來源。
5. 筆記間使用 Obsidian wikilinks；若匯入其他 Markdown 系統，可依目標系統調整連結格式。
