# Seven Factors of Awakening — Markdown 專題庫

本資料夾以繁體中文整理七覺支（satta bojjhaṅgā），採用卡片盒筆記方式，所有檔案均為 Markdown。

- `Seven_Factors_of_Awakening.md`：全書導讀與閱讀路徑。
- `data/`：文獻與傳承資料筆記。
- `note/`：可獨立重組的永久筆記。
- `idea/`：延伸思考與可執行的生活實驗。
- `term/`：術語定義與中英文維基百科入口。
- `moc/`：概念地圖與 Mermaid 關係圖。

筆記中的 Wikilinks 以檔名為目標，可在 Obsidian、Logseq 等支援 Wikilinks 的工具中使用。文獻筆記所附連結用於回到原始經典、期刊頁、教師講座或書籍資料。

證據分層原則：早期經典與傳承材料用來說明佛教修道脈絡；現代正念、認知與平等心研究只用來討論部分可測心理現象，不把它們直接等同於七覺支整體或覺悟。
