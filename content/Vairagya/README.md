# Vairagya 知識書庫

本資料夾以卡片盒筆記法整理 Vairāgya（離欲／不執著）主題。

## 資料夾
- `data/`：原典、研究、論文、書籍與訪談的文獻筆記（27 篇）
- `note/`：跨來源歸納的永久筆記（20 篇）
- `idea/`：延伸思考與可實作行動（7 篇）
- `term/`：概念定義與雙向 wikilinks（45 篇）
- `moc/`：Mermaid 概念地圖（3 篇）
- `Vairagya.md`：全書導讀、閱讀路徑與完整索引

## 使用方式
將整個資料夾匯入 Obsidian 或支援 wikilinks 與 Mermaid 的 Markdown 筆記工具。筆記之間使用相對路徑連結；檔名即卡片標題。文獻、永久與靈感卡片均有「思與行」及「參考」，並連回根目錄導讀。

## 內容說明
文獻涵蓋南亞瑜伽與《薄伽梵歌》、早期佛教、耆那教、伊斯蘭蘇非傳統、基督教神秘思想、斯多噶哲學、道家思想，以及現代心理學與自願簡樸研究。另收錄原典、研究論文、系統性回顧、專書與訪談。不同傳統採比較而不混同的處理方式。

研究狀態截至 2026-11-18。來源以可公開檢索的原典、學術出版頁、PubMed、期刊摘要、出版社資訊與訪談為主；部分出版物全文可能需要機構或付費存取。
