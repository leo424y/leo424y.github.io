# Saṅkhāra 知識書庫

本書庫依卡片盒筆記法整理，分為文獻資料、永久概念、延伸靈感、概念詞條與概念地圖。根目錄的 `Saṅkhāra.md` 是全書導讀。

- 文獻筆記以原典、傳承教學、辭典與學術研究為依據；引用連結供後續查證。
- 永久筆記以單一見解為單位，透過 wikilinks 連結其他卡片。
- 靈感筆記把概念轉成觀察、研究與行動實驗。
- 概念詞條以定義為主，附中文／英文維基百科條目作為起點；維基百科不是本書的主要學術證據。
- 概念地圖使用 Mermaid，建議在支援 Mermaid 的 Markdown 編輯器中檢視。

重要方法提醒：saṅkhāra／saṃskāra 在不同經典、部派與傳承中並非單一固定概念。本書將早期經典、上座部阿毘達磨、泰國森林傳統、葛印卡內觀、瑜伽行派與中觀分層處理；個別傳承的教學詮釋不等同所有傳統的共同定義。
