Ubuntu 常以關係性人格與相互依存來描述倫理生活，強調人之所以成為人，與他人及共同體的關係密不可分。但 Ubuntu 的思想與實踐並非單一固定版本，必須追問其具體語言、地區、思想家與歷史脈絡。

它對價值多元研究的貢獻，不是提供另一個「共同體價值」去取代個人自由，而是讓分析者重新檢查：誰被當成價值主體？關係、照顧與共同體是否具有獨立的倫理重要性？如何在關係責任與個人自主之間處理張力？

## 思與行
* 在團體決策中同時詢問個人自主與共同體責任，不預設兩者只能選一。
* 避免把 Ubuntu 當成組織口號；與具體社群、作者和實踐者的知識建立對話。
* 比較 [[關係價值讓倫理焦點從個人偏好擴展到相互依存]]。
