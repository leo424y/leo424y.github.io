## 開始閱讀

從 [Social_Capital.md](Social_Capital.md) 開始。它包含全書概覽、理論脈絡、全球案例、批判方法、閱讀路徑與重要書目。

## 使用方式

- 將整個 `Social_Capital` 資料夾放入 Obsidian 或其他支援 Markdown 的筆記系統。
- `筆記名稱` 為內部連結；請保留檔名不變以維持連結。
- `moc/` 的 Mermaid 圖可在支援 Mermaid 的 Markdown 應用中檢視。
- `data/` 的外部來源連結為文獻入口，部分期刊可能需要機構訂閱；能公開取得的資料與全文已優先採用官方或開放來源。

## 資料使用提醒

這是一份研究導讀與知識整理，不是窮盡所有國家和語言的系統性回顧。文獻筆記摘要旨在忠實整理研究問題、主要論點與限制；引用時請回到原始來源核對全文、方法與版本。
